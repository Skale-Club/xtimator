# Autonomous acceptance campaign — 2026-11-24

Status: running on `feat/autonomous-launch-qa`, from production release `1f4863dc`.
This record is evidence of work in progress, not public-launch approval.

## Scope and execution

- Per-run synthetic owned identities and tenant data on the existing Supabase development project; production data is excluded.
- Actual app, browser, database, upload, job and PDF paths. AI/media provider fixtures are explicitly synthetic; real provider/hardware capabilities remain separate gates.
- Chromium desktop, WebKit/iPhone and Chromium/Android emulation, one worker and zero automatic retries.
- Every mandatory scenario needs fresh evidence in its declared browser matrix. Missing, skipped, flaky and duplicate evidence blocks the campaign.
- Heavy execution runs on GitHub Actions. The Surface initially had 0.7 GB free; only lightweight scripts and targeted infrastructure tests ran locally.
