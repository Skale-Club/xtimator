# Requirements: v1.8 - Iterative Estimate Refinement

## v1.8 Requirements (SEED-006)

### Text Refinement

- [ ] **REFINE-01**: Estimate editor tab shows a collapsible "Refine this estimate" section below the editor with a text input field
- [ ] **REFINE-02**: API route `POST /api/estimates/[id]/refine` accepts `{ instruction: string }` and applies changes to the existing estimate
- [ ] **REFINE-03**: Refinement creates a new estimate version (increment `version_number`, set `is_current = true` on new, `false` on previous); previous version preserved

### Voice Refinement

- [ ] **REFINE-04**: Refine section has a microphone button that opens an inline recorder (not full-screen) with ~30 second maximum
- [ ] **REFINE-05**: Recording uses Whisper transcription → instruction text → same refine pipeline as text input

### Photo Refinement

- [ ] **REFINE-06**: Refine section has a camera/photo button that opens photo upload (reuse PhotoDropZone pattern)
- [ ] **REFINE-07**: Photo analyzed via Claude Vision → result used as context in refinement pipeline (existing estimate + instruction)
