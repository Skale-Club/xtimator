# Requirements Archive: v1.4 — Estimate Plain Text & Pricing Tools

> Archived 2026-05-08 — all 8 requirements validated.

## v1.4 Requirements

### Plain-text Estimate Output

- [x] **PLAINTEXT-01**: Usuário vê o orçamento em formato texto simples na aba "Plain Text" do editor de orçamento (ao lado de PDF e Web Link)
- [x] **PLAINTEXT-02**: Usuário copia o texto do orçamento com 1 clique (copy-to-clipboard); um toast de confirmação aparece após a cópia
- [x] **PLAINTEXT-03**: O texto gerado usa o template configurado pela empresa — saudação (`Hey {client_name}`), frase de abertura, listagem de categorias + itens + preços, total, frase de fechamento e assinatura (`{owner_name}`, `{company_name}`)
- [x] **PLAINTEXT-04**: Usuário pode editar o texto gerado diretamente no preview antes de copiar (override pontual — não altera o template salvo)
- [x] **PLAINTEXT-05**: Usuário configura o template da empresa em `/settings/estimate-templates` com variáveis suportadas: `{client_name}`, `{company_name}`, `{owner_name}`, `{total}`, `{items_breakdown}`

### Bulk Price Adjustment

- [x] **BULKPRICE-01**: Usuário seleciona uma categoria do price book e aplica um ajuste percentual (+/-%) em todos os itens dessa categoria de uma vez
- [x] **BULKPRICE-02**: Antes de confirmar, usuário vê preview dos preços atuais vs novos preços para todos os itens afetados
- [x] **BULKPRICE-03**: Ajuste confirmado é aplicado atomicamente a todos os itens da categoria (todos ou nenhum)

## Deferred to Future Milestones

- **Markdown variant** — output em `**bold**` para canais que renderizam markdown (Slack, Discord) — v1.5
- **JSON export** — para empresas que querem integrar com CRM próprio — v2
- **Bulk price adjustment across all categories** — aplicar o mesmo % a todo o price book de uma vez — v1.5
- **Versionamento temporal de preços** (preço de 2024 vs 2026) — v2
- **Per-company AI provider selection** — hoje é platform-level; futuro per-company — v2

## Out of Scope

- Disclaimer de IA no texto do orçamento — decisão intencional
- Integrações de mensageria nativas (Twilio SMS, WhatsApp Business API)
- Template por idioma (EN/PT-BR/ES por estimate) — i18n do template fica para v1.5
- Ajuste de preço retroativo em orçamentos já enviados
