## Phase Details

### Phase 34: Client-Project Quick Actions Verification

**Goal**: Verify and ensure all client-project association features work correctly from end to end

**Depends on**: Phase 29-30 (completed in v1.5)

**Requirements**: CLIENTASSOC-01, CLIENTASSOC-02, CLIENTASSOC-03, CLIENTASSOC-04

**Success Criteria** (what must be TRUE):
  1. User can create a project from the client detail page by clicking "New Project" — project is pre-linked to that client
  2. User is redirected to the capture screen immediately after creating project from client detail
  3. Projects without a client show "Link client" card in Overview tab
  4. User can link an existing client to a project from the Link Client card
  5. After AI estimate generation, if client name is detected, a non-blocking toast appears for user to accept/dismiss
