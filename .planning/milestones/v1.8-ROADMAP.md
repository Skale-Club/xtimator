# Roadmap: v1.8 - Iterative Estimate Refinement

## Overview

SEED-006: Adds a refinement panel to the estimate editor where users can send instructions (text/voice/photo) to update the estimate without regenerating from scratch.

**Milestone**: v1.8
**Granularity**: Standard
**Duration**: 3 phases

## Core Value Alignment

This feature directly amplifies the core value: *"A business owner can go from job site audio recording to a sent, professional estimate in under 5 minutes without touching a keyboard."*

The refinement panel completes the workflow by giving users surgical control over the generated estimate — update specific items without discarding the whole draft.

## What This Enables

- **Precision over regeneration**: User says "add gutter cleaning, 80ft" → Claude updates just that line
- **Mobile-first voice refinement**: Inline ~30s recorder (not full-screen /capture)
- **Evidence attachment**: Upload photo of a missed area → Claude Vision incorporates it
- **Version safety**: Every refinement creates a new version; previous state preserved

## Phase Details

### Phase 35: Text Refinement

**Goal**: User can type a refinement instruction and update the existing estimate without regenerating from scratch

**Depends on**: Phase 34 (estimate editor must be functional)

**Requirements**: REFINE-01, REFINE-02, REFINE-03

**Success Criteria** (what must be TRUE):
  1. Estimate editor tab shows a "Refine this estimate" section below the editor
  2. User can type an instruction (e.g. "Add gutter cleaning, 80ft") and click Send
  3. New estimate version is created with the applied change; previous version preserved
  4. Version selector shows the new version; user can revert to any previous version
  5. Refine action uses the existing estimate JSON + user instruction + company price book as context

**Plans**: TBD

**UI hint**: yes

### Phase 36: Voice Refinement

**Goal**: User can record a short voice instruction inline in the estimate editor

**Depends on**: Phase 35

**Requirements**: REFINE-04, REFINE-05

**Success Criteria** (what must be TRUE):
  1. Refine section has a mic button next to the text input
  2. Tapping mic opens inline recorder (not full-screen) with ~30 second max
  3. Recording shows timer and waveform feedback
  4. After recording stops, Whisper transcribes → instruction auto-fills → sent to refine pipeline
  5. Refine section shows "Recording..." state during capture

**Plans**: TBD

**UI hint**: yes

### Phase 37: Photo Refinement

**Goal**: User can attach a new photo as evidence for estimate refinement

**Depends on**: Phase 36

**Requirements**: REFINE-06, REFINE-07

**Success Criteria** (what must be TRUE):
  1. Refine section has a camera button next to text/voice inputs
  2. Tapping camera opens photo upload (reuse PhotoDropZone pattern)
  3. Photo is analyzed via Claude Vision → generates context for refinement
  4. Refine pipeline uses photo analysis + existing estimate + user context
  5. Refinement result shown with applied changes; photo visible in refinement history
