## Milestone Summary

**Key decisions:**
- **Refine stays synchronous inline** (passthrough StepRunner, not Inngest) — preserves the editor's preview-then-save UX while still routing refine through the shared graph/ingestion/prompt/guardrails (user decision 2026-06-21).
- **Single typed `FailureReason`** drives both the HTTP boundary (`XtimatorError`) and per-channel reply copy; markers `ProvidersUnavailableError`/`InvalidEstimateOutputError` map to `provider_unavailable`/`invalid_output`.
- **zod is the authoritative output gate** (`estimateOutputSchema`, single-sourced via `z.infer`); the provider-fallback seam wraps a bounded schema-retry so generate AND refine inherit fallback + validation.
- **Correlation id = the existing attemptId** (Phase 91/92 lineage promoted), not a new concept.
- **Test isolation root cause was import-latency under vitest forks-pool contention**, not mock-state leakage — fixed at the test-authoring level (per-file timeout), no production change, no global config mock-reset.
- **CI typecheck is scoped** (`tsconfig.ci.json`, app/lib only) because full `tsc` is pre-existing-red on tests-only errors.

**Tooling note:** GSD's `init phase-op N` prefix-matches phase numbers, so 99 collided with 999.1 and 100 with 1000 — the v4.5 phase dirs were created with short `N-slug` names FIRST so they win the `.startsWith` match.

**Tech debt (non-blocking):** GUARD-04 totals_discrepancy metric is log-only (not trace-attached); two pre-existing non-test working-tree files left untouched.

**Deferred human UAT:** live provider-outage fallback; editor refine end-to-end; needs-details banner + CTA; WhatsApp partial-batch reply wording; CI-gate-goes-red-on-broken-metric.
