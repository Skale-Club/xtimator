# Quick Task 260724-r1q — Plan

## Goal

Bring the whole-repo bare `npx tsc --noEmit` back to **0 errors** (it currently
reports 20, all in `tests/**`). CI's "Bare typecheck (advisory, non-blocking)"
step is red; this drift was introduced by the quick-260723 image-position work.

tests/eval` must stay green.

## Root causes (20 errors, 12 files)

1. **TS2741 — `image_position` missing** (8): dev branch added required
   `image_position: { scale; x; y } | null` to `PriceBookItem` /
   `DeletedPriceBookItem` (see `lib/queries/price-book.ts`). Fixtures predate it.
2. **TS2556 — spread into zero-arg mock** (7): `vi.fn(async () => {})` /
   `vi.fn(() => ({...}))` infer a no-param signature, so the deferred wrapper
   `(...args: unknown[]) => mock(...args)` can't spread `unknown[]` into them.
3. **TS2322 — Photo `position` missing** (2): `Photo` gained required
   `position: {...} | null`; one photo fixture predates it.
4. **TS2322 — `unit: null`** (2): `input.sections` inferred from `baseInput()`
   has `unit: string`; reassigning items with `unit: null` violates it. Schema
   (`estimate.ts`) is `z.string().nullable()`, so any valid string parses the
   same — tests only assert item-count bounds.
5. **TS2352 — DigestEmailItem cast** (1): needs `as unknown as Record<...>`.
