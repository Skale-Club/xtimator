# Modern Voice Recorder — New Xtimate popup (pause + REC button)

## Context

O gravador de voz do popup New Xtimate está visualmente datado em relação ao restante do fluxo de geração (que hoje tem glassmorphism bar, progress bar real, etc.): o botão principal usa ícone de microfone (Mic/MicOff) com `animate-pulse` opaco, a tela de gravação tem um bug de `<p>` aninhado no timer, e **não existe pause** — parar é destrutivo (finaliza a take e dispara o pipeline). Pedido do usuário: visual moderno, botão de REC clássico (ponto vermelho, não mic) e botão de pause durante a gravação.

Decisões do usuário:
- Superfície principal: o botão de gravar do popup + a tela que aparece durante a gravação.
- Visual idle: **vidro + ponto vermelho** (glass circular com ponto REC central; ponto cresce no hover).
- Restyle **visual** também nos demais gravadores (inline do projeto, ai-voice-dialog, refine) via componente compartilhado — **pause só no popup**.
- Todas as strings do app em inglês via `t()` (regra do projeto).

## Arquitetura da mudança

### 1. Relógio pause-aware (components/capture/capture-recorder.tsx)

Hoje: `elapsed = performance.now() - startTimeRef.current` (tick de 250ms). Pause quebraria tudo (timer, hard cap 10min, cor do ring, duração faturada no Whisper).

- Novo helper puro exportado (ao lado de `finalizeDurationSeconds` ~:78, para testes):
  ```ts
  export function computeElapsedMs(accumulatedMs: number, segmentStartMs: number | null, nowMs: number): number {
    return accumulatedMs + (segmentStartMs === null ? 0 : nowMs - segmentStartMs)
  }
  ```
- Substituir `startTimeRef` por `accumulatedMsRef` (soma dos segmentos gravados) + `segmentStartRef: number | null` (null = pausado/idle). Novo estado `isPaused`.
- `tick()` usa `computeElapsedMs(...)` — thresholds (WARN 9:00 / AMBER 8:00 / RED 9:30 / HARD_CAP 10:00) passam a contar **só tempo gravado**; durante pause o valor é constante (setState com mesmo número = no-op React; intervalo pode continuar rodando).
- `pauseRecording()` (novo): guarda `rec.state === 'recording'`; acumula o segmento, zera `segmentStartRef`, snapshot em `elapsedMsRef`, `MediaRecorder.pause()` (nativo — sem dataavailable durante pause), `setIsPaused(true)`. **Não** toca stream/tracks/AudioContext (o guard de permissão-revogada precisa da track viva).
- `resumeRecording()` (novo): guarda `rec.state === 'paused'`; `rec.resume()`, `segmentStartRef = performance.now()`, `setIsPaused(false)`.
- `stopRecording()` (~:401): preservar a ordem snapshot-antes-de-`.stop()` (fix do bug duration=0, 260707-grq) usando `computeElapsedMs`; `.stop()` é válido a partir de 'paused' também; adicionar `setIsPaused(false)`.
- `startRecording()` (~:909): reset `accumulatedMsRef=0`, `segmentStartRef=performance.now()`, `setIsPaused(false)`.
- Feature-gate: `SUPPORTS_PAUSE` (module-level, checa `MediaRecorder.prototype.pause`, SSR-safe) — sem suporte, UI degrada pro binário atual.
- Guards verificados (sem mudança): beforeunload e mute/inactive continuam ativos durante pause (`isRecording` permanece true); Generate continua `disabled={!hasAnyInput || isRecording}` (cobre paused); pre-flight `MIN_RECORDING_MS` inalterado; duração faturada = tempo gravado apenas.

## Testes / Verificação

- **Unit novos** (`computeElapsedMs`): segmento vivo `(0,1000,5000)=4000`; congelado `(4000,null,999999)=4000`; retomado `(4000,10000,12000)=6000`; multi-ciclo; hard-cap conta só tempo gravado.
- **Estáveis**: exports `finalizeDurationSeconds`/`MIN_RECORDING_MS` (capture-duration.test.ts) e `AMBER_AT_MS`/`RED_AT_MS` (recorder-warning-thresholds.test.ts) intocados; e2e `capture-mic`/`capture-timer` testids e geometria do FAB preservados.
- **Gates**: `npx tsc --noEmit` + eslint no baseline; `npx vitest run tests/unit/capture/` verde.
- **Manual pós-deploy**: gravar → pausar (timer congela, waveform acalma, halo some, "Paused" âmbar) → retomar → parar → pipeline gera normalmente com duração = só o tempo gravado; revogar mic durante pause → encerra gracioso; gravador inline/dialogs mostram o ponto REC novo.

## Edge cases cobertos no design

- Hard cap não dispara em pause (elapsed congelado); dispara ≤250ms após retomar passando de 10:00 gravados.
- Aba oculta pausada: sem drift (valor independe do relógio).
- Permissão revogada em pause: track viva → guard dispara → stop válido a partir de 'paused', duração = acumulado.
- Duplo-clique pause/resume: idempotente via `rec.state`.
- Sem suporte a pause (raro): botão não renderiza, UX atual binária preservada.
