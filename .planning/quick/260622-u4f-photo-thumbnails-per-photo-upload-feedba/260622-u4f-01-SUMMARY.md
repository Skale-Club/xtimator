# Phase quick-260622-u4f Plan 01: Photo Thumbnails + Per-Photo Upload Feedback + 15-Photo Cap Summary

Per-photo thumbnail strip with uploading/done/error feedback, a working remove (×) control, and a hard 15-photo cap in the New Xtimate capture popup — without changing the Generate pipeline (still reads `uploadedPhotos`, done photos only).

## What Was Built

- **`photoItems` model** (`PhotoItem { id, status: 'uploading'|'done'|'error', previewUrl, photo? }`): the per-photo source of truth driving the thumbnail strip. `isUploadingPhotos` is now derived (`photoItems.some(uploading)`), replacing the standalone boolean. `uploadedPhotos: Photo[]` is kept as the pipeline source — each item appends its `Photo` on flip to `done`, so Generate/analyze gating is unchanged.
- **15-photo hard cap**: pure exported `clampToPhotoLimit(currentCount, incoming)` → `{ take, overflowed }`. `handlePhotoFileChange` clamps the selection to remaining slots, `toast.info(t('You can add up to 15 photos.'))` on overflow, the add button is `disabled` at the cap, and the button label shows `N/15` once any photo exists (else `t('Photos')`).
- **Instant placeholders → real thumbnails**: each accepted file mints a `crypto.randomUUID()` id + `URL.createObjectURL(blob)` preview and pushes an `uploading` item BEFORE awaiting upload, then flips to `done` (with the created `Photo`) or `error`. Uploads run via `Promise.all` so multiple photos progress in parallel.
- **`PhotoThumbnailGrid`** (exported presentational component): wrap strip of ~56px (`h-14 w-14`) rounded `object-cover` thumbnails; uploading spinner overlay, error overlay, and a remove (×) button (`data-testid="capture-remove-photo"`). Renders nothing when empty. Wired into the horizontal popup layout just above the footer.
- **No object-URL leaks**: `handleRemovePhoto` revokes the item's `previewUrl`, removes it from `photoItems` (+ `uploadedPhotos` if it was done), and best-effort `deletePhoto`. An unmount effect revokes every remaining preview URL via a `photoItemsRef` mirror.
- **i18n**: new strings `t('You can add up to 15 photos.')` and `t('Remove photo')`.
