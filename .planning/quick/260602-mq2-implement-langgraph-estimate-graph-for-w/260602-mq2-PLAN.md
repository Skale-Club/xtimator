**State definition:**

```typescript
import { Annotation, StateGraph, Send, START, END } from '@langchain/langgraph'
import type { WhatsAppMessage } from '@/lib/whatsapp/types'

// currentMessage is only populated during processMessage fan-out via Send.
// It is optional so the base state (without Send override) remains valid.
const EstimateState = Annotation.Root({
  companyId:        Annotation<string>(),
  projectId:        Annotation<string>(),
  ownerPhone:       Annotation<string>(),
  messages:         Annotation<WhatsAppMessage[]>(),
  currentMessage:   Annotation<WhatsAppMessage | undefined>(),
  mediaResults: Annotation<Array<{ msgId: string; ok: boolean; reason?: string }>>({
    reducer: (cur, update) => [...cur, ...update],
    default: () => [],
  }),
  estimateId:       Annotation<string | undefined>(),
  estimateLanguage: Annotation<string | undefined>(),
  isVague:          Annotation<boolean | undefined>(),
})
```

**Node: supervisor**
- Reads `state.messages`
- Returns `Send[]`: one `new Send('processMessage', { ...state, currentMessage: msg })` per message
- If `state.messages` is empty or undefined, returns `[]` which will route to `END`

**Node: processMessage**  
- Reads `state.currentMessage` (the single message injected by Send)
- Implements the same logic as the current `step.run('process-${msg.id}')` body:
  - `text` → insert recording row, return `{ mediaResults: [{ msgId, ok: true }] }`
  - `audio` → download → upload to storage (using `getServerStorage()`, NOT `supabase.storage.from`) → transcribe → insert recording → return `{ mediaResults: [{ msgId, ok: true }] }`. On any error: catch, log, return `{ mediaResults: [{ msgId, ok: false, reason }] }`. NEVER re-throw.
  - `image` → download → upload to `'photos'` bucket via `getServerStorage()` (NOT `supabase.storage.from('photos').upload(...)`) → update whatsapp_messages row → analyzePhoto → insert photo row → return `{ mediaResults: [{ msgId, ok: true }] }`. On image download failure: catch, return `{ mediaResults: [{ msgId, ok: false, reason: 'download_failed' }] }`.
  - Unknown type: return `{ mediaResults: [{ msgId: state.currentMessage!.id, ok: true }] }` (same as current no-op)

**Node: gather**
- No-op convergence node: receives the merged mediaResults from all branches
- Returns `{}` (no state changes)

**Conditional: checkInputs** (edge from gather)
- `if state.mediaResults.some(r => r.ok)` → `'generateEstimate'`
- else → `'sendError'`

**Node: generateEstimate**
- Calls `generateEstimateForProject(state.companyId, state.projectId)`
- Returns `{ estimateId: result.estimateId, estimateLanguage: result.language }`

**Node: evaluateVagueness**
- Queries estimates table: `.select('total, sections:estimate_sections(items:estimate_items(id))')` by `state.estimateId`
- Calls `isVagueEstimate(est)`
- Returns `{ isVague: boolean }`

**Conditional: checkVague** (edge from evaluateVagueness)
- `if state.isVague` → `'askDetails'`
- else → `'sendConfirmation'`

**Node: askDetails**
- Calls `revertVagueEstimate(supabase, projectId, estimateId)`
- Inserts `awaiting_details` session (same TTL logic as current ask-details step.run)
- Sends WhatsApp message via `sendWhatsAppMessage` + `logOutboundMessage`
- Returns `{}`

**Node: sendConfirmation**
- Inserts `awaiting_confirm` session
- Queries estimate for total/sections
- Builds and sends confirmation message (same format as current confirm-and-session step.run)
- Returns `{}`

**Node: sendError**
- Sends the hardcoded error message (same text as current send-audio-error step.run)
- Returns `{}`

**Graph wiring:**

```typescript
const graph = new StateGraph(EstimateState)
  .addNode('supervisor', supervisorNode)
  .addNode('processMessage', processMessageNode)
  .addNode('gather', gatherNode)
  .addNode('generateEstimate', generateEstimateNode)
  .addNode('evaluateVagueness', evaluateVaguenessNode)
  .addNode('askDetails', askDetailsNode)
  .addNode('sendConfirmation', sendConfirmationNode)
  .addNode('sendError', sendErrorNode)
  .addEdge(START, 'supervisor')
  .addConditionalEdges('supervisor', supervisorEdge, ['processMessage', END])
  .addEdge('processMessage', 'gather')
  .addConditionalEdges('gather', checkInputsEdge, ['generateEstimate', 'sendError'])
  .addEdge('generateEstimate', 'evaluateVagueness')
  .addConditionalEdges('evaluateVagueness', checkVagueEdge, ['askDetails', 'sendConfirmation'])
  .addEdge('askDetails', END)
  .addEdge('sendConfirmation', END)
  .addEdge('sendError', END)

export function buildEstimateGraph() {
  return graph.compile()
}
```

**Important LangGraph v1.x API notes:**
- `addConditionalEdges(source, fn, destinations)` — the fn receives full state and returns a node name string
- `Send` is imported from `@langchain/langgraph` and used as `new Send(nodeName, partialState)`
- When supervisor returns `Send[]`, LangGraph fans out automatically; returning `[]` routes to END
- The `reducer` on `mediaResults` uses `(cur, update) => [...cur, ...update]` so parallel branches accumulate without overwrite

**SESSION_TTL_MINUTES constant:** define at module top: `const SESSION_TTL_MINUTES = 30`
