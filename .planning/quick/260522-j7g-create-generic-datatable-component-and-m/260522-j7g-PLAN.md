Target DataTable API (from locked context):
```typescript
export interface Column<T> {
  key: string
  header: string
  cell: (row: T) => React.ReactNode
  className?: string
}

export interface DataTableProps<T> {
  data: T[]
  columns: Column<T>[]
  getRowKey: (row: T) => string
  searchPlaceholder?: string
  searchFn?: (row: T, term: string) => boolean
  sortOptions?: Array<{ value: string; label: string; sort: (a: T, b: T) => number }>
  defaultSort?: string
  filterTabs?: Array<{ key: string; label: string; match?: (row: T) => boolean }>
  defaultFilter?: string
  emptyTitle?: string
  emptyDescription?: string
  emptyIcon?: LucideIcon
  onRowClick?: (row: T) => void
  renderMobileCard?: (row: T) => React.ReactNode
  headerRight?: React.ReactNode
}
```

  3. If `headerRight`: render it right-aligned in the top row (push it to the end with `ml-auto`)
  4. Empty all-data state: if `data.length === 0`, render `<EmptyState icon={emptyIcon ?? FolderOpen} title={emptyTitle ?? 'No items'} description={emptyDescription ?? ''} />`
  5. Empty search/filter state: if `displayData.length === 0 && data.length > 0`, render `<EmptyState icon={Search} title="No results match your filters" onClearFilter={() => { setSearch(''); setActiveFilter(filterTabs?.[0]?.key ?? 'all') }} />`

Desktop (`hidden md:block`): `<Table>` with `<TableHeader><TableRow>` mapping columns to `<TableHead className={col.className}>`, then `<TableBody>` mapping displayData to `<TableRow key={getRowKey(row)} onClick={onRowClick ?   7. Mobile (`md:hidden space-y-3`): if `renderMobileCard` is provided, map displayData with it; otherwise render nothing (mobile fallback is optional)
