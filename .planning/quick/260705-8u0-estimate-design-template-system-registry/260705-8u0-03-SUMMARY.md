# Phase 260705-8u0 Plan 03: Modern share-page document Summary

**New editorial-serif `EstimateDocumentModern` component wired into the public share page via a registry-resolved `templateId` ternary, reusing Classic's exact computed props/helpers with zero changes to `estimate-document.tsx`.**

## Accomplishments
- Public share-page visitors with `estimate_template_style='modern'` now see an editorial serif document (font-serif, hairline rule dividers, sparing brand-color text accents, a large standalone hero grand total, generous whitespace) instead of Classic's boxed-table letterhead look
- Companies on `'classic'` (or any legacy/null value) see the exact same share-page document as before this change — zero visual regression
- `estimate-view.tsx` now resolves the active template defensively through `isEstimateTemplateId`, never via raw string comparison, and swaps ONLY the document sub-tree — SignaturePad, Accept/Decline CTA, Invoices/Stripe panel, Estimate Terms card, and footer are byte-identical
- `getEstimateByShareToken` now selects `estimate_template_style` so the share page has the data it needs to pick a template

## Files Created/Modified
- `components/share/estimate-document-modern.tsx` - New view-mode-only React component (`EstimateDocumentModern`); renders company header, ESTIMATE title, project/bill-to info grid, summary, sections+items (desktop table + mobile stacked cards), totals (with hero grand total), terms, and attached photos, all with editorial serif styling
- `components/share/estimate-view.tsx` - Imports `EstimateDocumentModern` and the registry (`EstimateTemplateId`, `isEstimateTemplateId`, `DEFAULT_ESTIMATE_TEMPLATE_ID`); resolves `templateId` right after `documentData` is built; replaces the single hardcoded `<EstimateDocument mode="view">` render with a `templateId === 'modern' ? <EstimateDocumentModern .../> : <EstimateDocument mode="view" .../>` ternary, passing the exact same already-built props to whichever branch is selected
- `lib/queries/share.ts` - `getEstimateByShareToken`'s `companies` select now includes `estimate_template_style`; `ShareEstimateData['estimate']['company']` inline type gained `estimate_template_style: string` (no `?`, matching the `NOT NULL DEFAULT 'classic'` column)

## Decisions Made
- Skipped calling `readableTextColor` in the new component (see key-decisions above) — Modern's design brief explicitly forbids brand-color background fills, so the helper has no valid call site here; removed the resulting unused-import/unused-variable ESLint warning rather than force a spurious call
- Duplicated `formatAddress`, `formatDate`, and a trimmed `DOC_LABELS`/`DocLabels` (en/pt/es, only the keys this view renders) locally in the new file instead of exporting them from `estimate-document.tsx`, per the plan's explicit instruction and the hard scope limit forbidding any edit to that file
