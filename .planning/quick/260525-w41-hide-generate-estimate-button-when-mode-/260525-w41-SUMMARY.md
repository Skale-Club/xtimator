# Quick 260525-w41: Hide Generate Estimate Button in Audio Popup Summary

Wrapped the bottom Generate Estimate button block in `RecorderBody` with a `{mode !== 'audio' && (...)}` conditional so the audio popup no longer renders the dead UI button (audio mode auto-triggers `runPipeline` via `recorder.onstop` before the user could click it). Language selector remains visible in all modes.

## Change

Single conditional wrapper added around the existing bottom-button container in `components/capture/capture-recorder.tsx` (lines 667-680, post-edit):

```tsx
{/* Language selector — visible in all modes (used by runPipeline in audio too) */}
<div className="px-4 pt-4 pb-2">
  <EstimateLanguageSelector
    value={estimateLanguage}
    onChange={setEstimateLanguage}
  />
</div>
{/* Generate Estimate button — hidden in audio mode (recorder.onstop auto-triggers runPipeline) */}
{mode !== 'audio' && (
  <div className="px-4 pt-2 pb-6 sm:pb-8 mt-auto">
    <Button
      onClick={onGenerate}
      disabled={!hasAnyInput}
      className="w-full"
      size="lg"
      data-testid="generate-estimate-btn"
    >
      {t('Generate Estimate')}
    </Button>
  </div>
)}
```

This matches the established conditional pattern already in the same component at lines 592, 621, and 633.
