# Quick Task 260715-08i: Reorganize Admin Billing Page Summary

Client-side search/tier/auto-top-up filtering, per-column sorting (tier by rank, not alphabet) and 10/25/50 pagination on the admin billing table, plus the Platform AI Cost stat moved inline with the page header.

## What Was Built

**Task 1 — Billing table controls** (`9d2ce821` test, `a61ab6fd` impl)

Three pure helpers exported from `billing-table.tsx` so the logic is testable without rendering:
- `filterCompanies` — trims/lowercases the search term, matches `(c.name ?? '')` so null names never throw; `tier`/`autoTopup` skip on `'all'`; all three AND together.
- `sortCompanies` — copies via `[...companies]` before sorting (never mutates the prop), returns input order for a `null` key. Numeric subtraction for `credit_balance`/`realCostUsd`, `Number()` coercion for the boolean, and **`TIER_OPTIONS.indexOf` ranking for tier**.
- `paginate<T>` — generic slice.

`BillingTable` wires these through a `useMemo` filter→sort pipeline, then clamps the page at render time (`safePage = Math.min(page, totalPages)`). Controls bar mirrors `companies-controls.tsx` styling but uses plain `useState` — no URL state, since `realCostUsd` is computed server-side from `ai_cost_events` and isn't a sortable DB column. All 5 data headers toggle asc/desc with `aria-sort` on the `th`; the actions column stays unsortable. Distinct empty state when filters exclude every row.

**Task 2 — Header layout** (`48aa3eff`)

Title block and stat `Card` wrapped in one `flex flex-col gap-6 md:flex-row md:items-start md:justify-between` row. Card swapped `max-w-sm min-h-[120px]` for `w-full md:w-auto md:min-w-[240px] md:shrink-0`. `loading.tsx` mirrors it so the skeleton doesn't jump. Everything above the `return` in `page.tsx` — the `Promise.all`, batched `ai_cost_events` lookup, `costByCompany`, `companiesWithCost` — is byte-identical, guarded by an automated check.
