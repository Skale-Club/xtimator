**1. Export pure helpers** (above `BillingTable`, so tests import them without rendering):

```ts
export type SortKey = 'name' | 'credit_balance' | 'realCostUsd' | 'auto_topup_enabled' | 'tier'
export type SortDir = 'asc' | 'desc'
export type BillingFilters = { search: string; tier: string; autoTopup: string }

export function filterCompanies(companies: Company[], filters: BillingFilters): Company[]
export function sortCompanies(companies: Company[], key: SortKey | null, dir: SortDir): Company[]
export function paginate<T>(rows: T[], page: number, pageSize: number): T[]
```

- `filterCompanies`: trim + lowercase the search, match against `(c.name ?? '').toLowerCase()`; skip the search when the trimmed term is empty. `tier`/`autoTopup` are skipped when `'all'`. Map `autoTopup` `'on'` → `true`, `'off'` → `false`.
- `sortCompanies`: return `[...companies]` before sorting (**never mutate the prop**). Return the input order unchanged when `key` is `null`. Compare per key:
  - `'name'` → `(a.name ?? '').localeCompare(b.name ?? '')`
  - `'credit_balance'`, `'realCostUsd'` → numeric subtraction
  - `'auto_topup_enabled'` → `Number(a) - Number(b)` (false before true asc)
  - `'tier'` → **rank by `TIER_OPTIONS.indexOf(tier)`**, so free → pro → business; unknown tiers rank `-1` and sort first asc. Do NOT use `localeCompare` here — alphabetical order is meaningless for tiers.
  - Apply `dir === 'desc' ? -cmp : cmp`.
- `paginate`: `rows.slice((page - 1) * pageSize, page * pageSize)`.

**2. State in `BillingTable`:**
```ts
const [search, setSearch] = useState('')
const [tierFilter, setTierFilter] = useState('all')
const [autoTopupFilter, setAutoTopupFilter] = useState('all')
const [sortKey, setSortKey] = useState<SortKey | null>(null)   // null = keep server order (created_at desc)
const [sortDir, setSortDir] = useState<SortDir>('asc')
const [page, setPage] = useState(1)
const [pageSize, setPageSize] = useState(25)
```
`sortKey` starts `null` on purpose: the default view keeps the server's `created_at desc` order, so this change adds capability without silently reordering the existing page.

**3. Derivation pipeline** — `useMemo` on filter, then on sort:
```ts
const filtered = useMemo(() => filterCompanies(companies, { search, tier: tierFilter, autoTopup: autoTopupFilter }), [companies, search, tierFilter, autoTopupFilter])
const sorted = useMemo(() => sortCompanies(filtered, sortKey, sortDir), [filtered, sortKey, sortDir])
```
Then compute `totalPages = Math.max(1, Math.ceil(sorted.length / pageSize))`, clamp with `const safePage = Math.min(page, totalPages)`, and slice `paginate(sorted, safePage, pageSize)`. **Render from `safePage`, not `page`** — clamping in render avoids the setState-during-render / effect-loop trap when a filter shrinks the result set while on a late page. Also reset `setPage(1)` in each control's change handler.

**4. Controls bar** above the table (`flex flex-wrap items-center gap-2 mb-4`), styled per `companies-controls.tsx`:
