# Quick Task 260519: Admin Integrations Accent Fix

**One-liner:** Remove the amber/yellow super-admin accent from the admin shell
and make integration status badges use semantic colors instead of the global
primary color.

## Goal

The admin integrations page currently renders active tabs, primary buttons,
focus rings, and the super-admin banner in amber/yellow. That clashes with the
existing dark admin design and makes normal save actions look like warnings.

## Tasks

1. Update `app/admin/layout.tsx` so the admin shell uses the stable system
   blue accent for primary UI and focus rings.
2. Keep tenant branding available only through `--platform-primary` for nested
   preview surfaces that intentionally opt into it.
3. Update the integration cards so `Connected` reads as a semantic success
   state and `Not configured` remains subdued.
4. Run focused lint/build checks for the touched files.
