<context>
- Page mode (p3v) renders an 816×1056 min sheet; on a ~860px viewport the top ~600px is visible — user must scroll. Fit = scale the sheet so 1056px of height lands in (viewport − sheet top − pill clearance).
- CSS `zoom` (Baseline since 2024) scales layout too — unlike transform:scale it leaves no phantom scroll area, and mx-auto still centers the shrunken box. Applied to the existing page wrapper (mx-auto max-w-[816px]) so the invoice surfaces scale consistently with the sheet.
- The scroll container is the app shell's inner `<main class="overflow-y-auto">`; topbar is sticky above it, so clamp the measured sheet top to the main's own top (mid-scroll toggles would otherwise measure a negative top).
- Pill (estimate-floating-actions.tsx) is `fixed` bottom-center; internal useState for collapse is enough (no persistence ask). Chevron goes AFTER Send so the gear-leftmost order tests stay intact.
</context>
