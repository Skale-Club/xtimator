components/pwa/sw-register.tsx (CURRENT — 12 lines, registers unconditionally):
```typescript
'use client'

import { useEffect } from 'react'

export function SWRegister() {
  useEffect(() => {
    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('/sw.js').catch(() => {})
    }
  }, [])
  return null
}
```

public/sw.js (CURRENT — relevant lines 12-16, top of file):
```javascript
const CACHE_V = 'v1'
const SHELL   = `shell-${CACHE_V}`
const PAGES   = `pages-${CACHE_V}`

const KNOWN_CACHES = [SHELL, PAGES]
```

public/sw.js activate handler (CURRENT — lines 27-35, ALREADY evicts unknown caches):
```javascript
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys()
      .then((keys) => Promise.all(
        keys.filter((k) => !KNOWN_CACHES.includes(k)).map((k) => caches.delete(k))
      ))
      .then(() => self.clients.claim())
  )
})
```

Bumping CACHE_V to 'v2' is sufficient — the existing activate handler will evict shell-v1/pages-v1 on next activation because they will no longer be in KNOWN_CACHES.
