    - relativeLuminance({r:255,g:255,b:255}) ≈ 1; ({r:0,g:0,b:0}) ≈ 0 (WCAG sRGB linearization)
    - contrastRatio('#000000','#ffffff') ≈ 21 (within ±0.1); contrastRatio('#ffffff','#ffffff') ≈ 1

    - ensureReadableOnWhite('#1A1A1A') → returns the original color unchanged (already passes 4.5:1)
    - Invalid input to any function must NOT throw — return a safe default (document the chosen semantics: e.g. hexToRgb→null; the higher-level fns fall back to a legible default like '#000000' text / the input hex)

    3. Create `lib/color/contrast.ts` — a PURE module (no React, no DOM, no I/O) exporting:
       - `hexToRgb(hex: string): { r: number; g: number; b: number } | null` — trim, strip leading '#', expand 3→6 digits, validate `^[0-9a-fA-F]{6}$`, parse. Return null on invalid. (Reuse the parsing shape from hexToHslTriplet.)
       - `relativeLuminance(rgb: {r:number;g:number;b:number}): number` — WCAG: channel/255, then c<=0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4; L = 0.2126*R + 0.7152*G + 0.0722*B.
       - `contrastRatio(hex1: string, hex2: string): number` — luminances L1,L2 from hexToRgb→relativeLuminance; (max+0.05)/(min+0.05). If either hex is invalid, treat that side's luminance safely (document: e.g. invalid → 0/black) so it never throws; returns 1..21.
       - `readableTextColor(bgHex: string): '#000000' | '#ffffff'` — return whichever of black/white has the GREATER contrastRatio against bgHex (case 2: fixed white text over a brand fill). Invalid input → '#000000'.
       - `ensureReadableOnWhite(hex: string, minRatio = 4.5): string` — if hexToRgb(hex) is null, return '#000000'. If contrastRatio(hex,'#ffffff') >= minRatio, return the ORIGINAL hex unchanged. Otherwise convert to HSL, then reduce L in small steps (e.g. decrement L by ~2% and re-check contrast, or binary-search L in [0, currentL]) preserving H and S, until contrastRatio(result,'#ffffff') >= minRatio; convert back to a normalized '#rrggbb' hex and return it (case 1: brand text on white, hue preserved).
