# Quick Task 260523: Align page spacing

## Goal

Make page top spacing match page side spacing. Remove the extra app-shell top padding and normalize primary app page wrappers so the first page content starts at the same inset as the left/right page padding.

## Tasks

1. Remove global top padding from the authenticated app `main`.
2. Convert main page wrappers from `px-* py-*` with larger top spacing to symmetric `p-*` where appropriate.
3. Keep bottom spacing and section-internal spacing where it serves content rhythm rather than header offset.
4. Run focused type/lint checks for touched layout files.
