```typescript
/**
 * Split an assistant reply into ordered, WhatsApp-sized chunks for sequential
 * sending. Splits first on blank-line (paragraph) boundaries; any paragraph
 * exceeding maxLen is further split on sentence/newline boundaries (greedy
 * packing), with a hard slice as the last resort. Empty/whitespace chunks are
 * dropped. A short reply yields a single chunk.
 */
export function splitReply(text: string, maxLen = 1000): string[]
```

Implementation guidance:
1. If `!text || !text.trim()` return `[]`.
2. Split on `/\n\s*\n/` into paragraphs; `.map(p => p.trim())` and drop empties.
3. For each paragraph: if `length <= maxLen`, keep as one chunk. Else split into sentences/lines (e.g. split on `/(?<=[.!?])\s+/` then also on `\n`), greedily pack pieces into a buffer until adding the next would exceed `maxLen`, flushing the buffer as a chunk. If a single piece still exceeds `maxLen`, hard-slice it into `maxLen`-sized substrings.
4. Trim every emitted chunk and drop any that become empty.
5. Preserve order throughout.

TypeScript strict: no `any`, explicit return type. Match surrounding code style (2-space, single quotes, no semicolons-optional matches existing files which OMIT semicolons — follow intent-router.ts style: no trailing semicolons).
