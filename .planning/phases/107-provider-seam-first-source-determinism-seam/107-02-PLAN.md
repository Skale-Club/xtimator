<!-- VERIFIED current OpenRouter web-search server-tool REQUEST (June 2026 docs). -->
<!-- tools entry uses parameters.engine nesting (NOT a top-level `engine`). -->
OpenRouter request body (SEPARATE call, NO forced create_estimate, NO tool_choice):
```json
{
  "model": "<model>",
  "max_tokens": 1500,
  "messages": [
    { "role": "system", "content": "<research instructions>" },
    { "role": "user", "content": "<buildResearchSearchPrompt output>" }
  ],
  "tools": [
    {
      "type": "openrouter:web_search",
      "parameters": { "engine": "exa", "max_results": 5 }
    }
  ]
}
```
engine ∈ "auto"|"native"|"exa"|"firecrawl"|"parallel"|"perplexity"; DEFAULT here = "exa".
Response: assistant message carries `annotations: [{ type:'url_citation', url_citation:{ url, title, content, start_index?, end_index? } }]`
(content holds the snippet excerpts). The model's text (message.content) holds the
per-item prices; pair each price with its url_citation annotation for evidence.
usage.server_tool_use.web_search_requests counts billed searches.

<!-- VERIFIED current Anthropic web_search tool REQUEST/RESPONSE (June 2026 docs). -->
Anthropic tools entry:
```json
{
  "type": "web_search_20250305",
  "name": "web_search",
  "max_uses": 5,
  "user_location": { "type": "approximate", "city": "Austin", "region": "TX", "country": "US" }
}
```
Response content blocks include `web_search_tool_result` → `content:[{ type:'web_search_result', url, title, page_age }]`
and final text blocks carry `citations:[{ type:'web_search_result_location', url, title, cited_text }]`.
Use url + cited_text as the source_url + snippet evidence.
On error the API still returns 200 with `web_search_tool_result_error` (error_code) — treat as miss.
