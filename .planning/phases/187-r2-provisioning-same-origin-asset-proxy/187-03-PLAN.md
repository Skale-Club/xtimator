<objective>
Ship the route itself: `GET /storage/{bucket}/{key}` — a same-origin, credential-free
URL that serves any storage object from R2 when it is there and from Supabase when it
is not, with the object's real content type, a per-bucket cache policy, and a refusal
for anything outside the five buckets or outside the caller's tenant.

Purpose: this is the URL that later phases rewrite into. Because it reads through to
Supabase (Plan 01), R2 may be completely empty and nothing breaks — which is what makes
Phases 190/191/192 reversible. The route also puts images on the same origin as the
Cloudflare zone, which is the payoff the whole milestone exists for (41 image
references / ~1.9 MB per cold landing visit currently bypass the edge entirely).

Output: the route handler, a tenant-ownership gate, route tests, and the documented
contract. **Nothing is rewritten to use the route in this phase** — no DB row, no
`getPublicUrl()` output, no component. That is Phase 190/192.
</objective>

    Create `app/storage/[bucket]/[...key]/route.ts`.

    ```typescript
    export const runtime = 'nodejs'      // AWS SDK + service-role client are Node-only
    export const dynamic = 'force-dynamic'
    export async function GET(_req: Request, { params }: { params: Promise<{ bucket: string; key: string[] }> })
    ```

    Handler order — do not reorder, each gate is cheaper and stricter than the next:
    1. `const { bucket: rawBucket, key: segments } = await params`
    2. `if (!isProxyBucket(rawBucket)) return notFound()` — 404, not 400: the route does
       not enumerate which buckets exist.
    3. `const key = normalizeProxyKey(segments); if (key === null) return badRequest()` — 400.
    4. If `!isPublicProxyBucket(bucket)`: `if (!(await canReadPrivateKey(key))) return notFound()`
       — 404 rather than 403, so the response does not confirm that the object exists.
    5. `const asset = await fetchStoredAsset(bucket, key); if (!asset) return notFound()`
    6. Success response:
       ```typescript
       const headers = new Headers({
         'Content-Type': asset.contentType,
         'Cache-Control': cacheControlFor(bucket),
         'Content-Disposition': 'inline',
         'X-Content-Type-Options': 'nosniff',
         'X-Asset-Source': asset.source,
       })
       if (asset.contentLength !== undefined) headers.set('Content-Length', String(asset.contentLength))
       if (!isPublicProxyBucket(bucket)) headers.set('Vary', 'Cookie')
       return new Response(asset.body as BodyInit, { status: 200, headers })
       ```
       `Content-Disposition: inline` (no filename) is what makes an image render and a
       PDF open in-browser instead of downloading — Success Criterion 1.
       `Vary: Cookie` on private buckets is belt-and-braces next to `private, no-store`.
    7. `notFound()`/`badRequest()` are local helpers returning
       `new Response('Not found', { status: 404, headers: { 'Cache-Control': 'private, no-store', 'Content-Type': 'text/plain' } })`
