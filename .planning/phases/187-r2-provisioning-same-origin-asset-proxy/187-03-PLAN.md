<objective>
Ship the route itself: `GET /storage/{bucket}/{key}` — a same-origin, credential-free
URL that serves any storage object from R2 when it is there and from Supabase when it
is not, with the object's real content type, a per-bucket cache policy, and a refusal
for anything outside the five buckets or outside the caller's tenant.

Purpose: this is the URL that later phases rewrite into. Because it reads through to
Supabase (Plan 01), R2 may be empty and nothing breaks. The route also puts images on
the same origin as the Cloudflare zone, which is the payoff the whole milestone exists
for (41 image references / ~1.9 MB per cold landing visit currently bypass the edge).

Output: the route handler, a tenant-ownership gate, route tests, a real-HTTP header
check, and the documented contract. **Nothing is rewritten to use the route in this
phase** — no DB row, no `getPublicUrl()` output, no component. That is Phase 190/192.
</objective>

**Two axes, deliberately separate — do not conflate them in the route.**
Access: `logos` + `platform-brand` are fetchable without auth.
Cache: `platform-brand` → immutable; `logos` → revalidating (its writers use stable
keys with `upsert: true`, so an immutable logo would pin a stale image in unpurgeable
browser caches); `photos`/`audio`/`pdfs` → `private, no-store`.

    Handler order — do not reorder, each gate is cheaper and stricter than the next:
    1. `const { bucket: rawBucket, key: segments } = await params`
    2. `if (!isProxyBucket(rawBucket)) return notFound()` — 404, not 400: the route does
       not enumerate which buckets exist.
    3. `const key = normalizeProxyKey(segments); if (key === null) return badRequest()` — 400.
    4. If `!isPubliclyReadableBucket(bucket)`: `if (!(await canReadPrivateKey(key))) return notFound()`

       Use `isPubliclyReadableBucket` for **access only**; never derive the cache header
       from it (see Plan 01 — `logos` and `platform-brand` are both publicly readable but
       get different cache directives).
    5. `const asset = await fetchStoredAsset(bucket, key); if (!asset) return notFound()`
    6. Success response:
       ```typescript
       const headers = new Headers({
         'Content-Type': asset.contentType,
         'Cache-Control': cacheControlFor(bucket),     // CACHE axis — per-bucket map
         'Content-Disposition': 'inline',
         'X-Content-Type-Options': 'nosniff',
         'X-Asset-Source': asset.source,
       })
       if (asset.contentLength !== undefined) headers.set('Content-Length', String(asset.contentLength))
       if (!isPubliclyReadableBucket(bucket)) headers.set('Vary', 'Cookie')
       return new Response(asset.body as BodyInit, { status: 200, headers })
       ```
