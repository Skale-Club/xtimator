## Spacing Scale

Declared values (8-point scale, multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline tight spacing |
| sm | 8px | Between icon and label, compact padding inside cards |
| md | 16px | Card internal padding, nav item gaps, button padding |
| lg | 24px | Section internal padding, card gaps in grid |
| xl | 32px | Between nav and hero, between feature cards |
| 2xl | 48px | Section top/bottom padding (How It Works, Features) |
| 3xl | 64px | Hero section top/bottom padding, major section breaks |

Exceptions:
- Touch targets (hamburger, nav icon buttons): minimum 44px height (iOS Safari accessibility requirement — LAND-04)
- Nav bar height: 64px fixed (aligns with 3xl icon clearance)
- Step number badge diameter: 36px (multiple of 4, visually prominent without overwhelming)

Source: 8-point defaults; touch-target exception from LAND-04 iOS Safari requirement.

## Typography

| Role | Token | Size | Weight | Line Height | Tracking | Usage |
|------|-------|------|--------|-------------|----------|-------|
| Body | `--font-size-base` | 16px (1rem) | 400 (`--font-weight-normal`) | 1.5 (24px) | 0em | Step descriptions, feature benefit copy, nav anchor labels |
| Label | `--font-size-sm` | 14px (0.875rem) | 500 (`--font-weight-medium`) | 1.25 (20px) | 0em | Step number badges, section eyebrow labels (e.g. "How It Works"), footer copyright |
| Heading | `--font-size-xl` | 20px (1.25rem) | 600 (`--font-weight-semibold`) | 1.4 | -0.01em (`--tracking-tight`) | Card titles (step titles, feature titles), nav wordmark |
| Display | `--font-size-3xl` + fluid up | 30px–52px fluid | 700 (`--font-weight-bold`) | 1.15 | -0.02em (`--tracking-tighter`) | Hero headline only |
| Subheadline | `--font-size-lg` | 18px (1.125rem) | 400 (`--font-weight-normal`) | 1.6 | 0em | Hero subheadline, below the display headline |

Notes:
- Hero headline uses `clamp(1.875rem, 4vw + 1rem, 3.25rem)` for fluid sizing between mobile and desktop — stays within the display role.
- Maximum 4 declared sizes in use: sm (14), base (16), lg (18), xl (20), with display as a fluid variant of 3xl. Effectively 4 discrete steps plus the fluid hero variant.
- No decorative fonts. Inter at weight 700 provides sufficient impact for the hero display.

Source: `--font-size-*` and `--font-weight-*` tokens in `app/globals.css` Phase 9 Pillar C block.

## Color

| Role | Token | Hex (dark mode) | Usage |
|------|-------|-----------------|-------|
| Dominant (60%) | `--background: 240 10% 3.9%` | `#0A0A0F` (near-black) | Page background, hero backdrop base |
| Secondary (30%) | `--card: 240 10% 3.9%` + elevated surface | `#13131A` / `#1A1A24` | Step cards, feature cards, nav bar surface |
| Accent (10%) | `--primary: 224 86% 60%` | `#406EF1` | See reserved list below |
| Accent-light | Secondary accent (not a semantic token) | `#7FA4F4` (HSL ≈ 218 85% 73%) | Gradient stops in hero backdrop, hover state glow on cards |
| Border | `--border: 240 3.7% 15.9%` | `#27272A` approx | Card borders; gradient border overlay uses `#406EF1` at 30% opacity on hover |
| Foreground | `--foreground: 0 0% 98%` | `#FAFAFA` | All primary body text |
| Muted text | `--muted-foreground: 240 5% 64.9%` | `#A1A1AA` approx | Step descriptions, feature body copy, footer copyright |
| Destructive | `--destructive` | N/A this phase | No destructive actions on landing page |

**Accent (`#406EF1`) reserved for:**
1. Primary CTA button background ("Get Started Free") — `bg-primary`
2. "Get Started" button in sticky nav (same as hero CTA)
3. Step number badge ring/border (1px border, not filled)
4. Hover elevation glow on How It Works and Features cards (`box-shadow: 0 0 0 1px hsl(var(--primary) / 0.4)`)
5. Focus ring on all interactive elements (`--shadow-focus: 0 0 0 3px hsl(var(--ring) / 0.45)`)
6. Eyebrow label text color for section headers ("How It Works", "Features")

**Accent-light (`#7FA4F4`) reserved for:**
1. Hero backdrop gradient (radial stop, low opacity ~15%)
2. Gradient text treatment on hero headline keyword (e.g., the word "estimate" or "5 minutes") — linear-gradient from `#406EF1` to `#7FA4F4`

**Gradient border micro-treatment (ui-ux-pro-max):**
- Resting state: `border: 1px solid hsl(var(--border))`
- Hover state: `border: 1px solid transparent; background-clip: padding-box` + `::before` pseudo with `linear-gradient(135deg, #406EF1 0%, #7FA4F4 100%)` at 40% opacity

Source: CONTEXT.md D-14, SEED-002 Color System, `app/globals.css` .dark scope, LAND-05.

## Layout Contract

### Breakpoints (Tailwind 4 defaults)

| Breakpoint | Min-width | Layout change |
|------------|-----------|---------------|
| `sm` | 640px | 2-col features grid |
| `md` | 768px | Full desktop nav visible, hamburger hidden |

| `xl` | 1280px | Max content width cap at 1200px centered |

### Page Structure (top → bottom)

```
<LandingNav />          sticky, top-0, z-50, backdrop-blur-md
<HeroSection />         min-h-screen or min-h-[90vh], flex center
<HowItWorksSection />   id="how-it-works", py-24 (3xl)
<FeaturesSection />     id="features", py-24 (3xl)
<FooterMinimal />       py-8, centered logo + copyright
```

### Nav Layout

```
[Logo + wordmark]                    [How It Works] [Features]    [Sign In] [Get Started]
←— left                                                                      right —→
```

Mobile (< md): Logo left + hamburger right. Sheet drawer contains: How It Works, Features, Sign In (ghost), Get Started Free (primary, full-width).

### Hero Layout

- Desktop (lg+): 2-column grid. Left: headline + subheadline + CTA stack. Right: product mockup SVG.
- Mobile (< lg): Single column, stacked. Mockup below CTA, reduced to 80% width, centered.
- Hero backdrop: radial gradient from `hsl(var(--primary) / 0.12)` at center to transparent at edges, layered over `--background`.

### How It Works Layout

- 3-step horizontal grid: `grid-cols-1 sm:grid-cols-3`
- Each step card: number badge (top) + Lucide icon + title + description
- Step number badge: 36px circle, border `1px solid hsl(var(--primary) / 0.6)`, text `text-primary font-semibold`
- Connector line between steps (desktop only): `1px dashed hsl(var(--border))` spanning between cards

### Features Grid Layout

- `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`
- Each card: icon (top) + title + 1-2 sentence benefit copy
- Fixed height cards with `h-full flex flex-col`

## Interaction Contract

### Sticky Nav
- Behavior: `position: sticky; top: 0; z-index: 50`
- On scroll > 0px: add `backdrop-blur-md bg-background/80 border-b border-border` transition (200ms ease)
- At top of page: `bg-transparent border-transparent`
- Transition property: `background-color, border-color, backdrop-filter` at 200ms ease

### Anchor Scroll
- "How It Works" → `scroll-behavior: smooth` to `#how-it-works`
- "Features" → smooth scroll to `#features`
- Uses native `href="#section-id"` — no JS scroll handler needed

### Mobile Nav (Sheet)
- Trigger: hamburger `Menu` lucide icon, 44px touch target
- Sheet side: "right" (consistent with shadcn sheet default)
- Sheet width: full width on xs, 320px on sm+
- Sheet close: X icon top-right, tap outside

### Card Hover
- How It Works cards: `transition-shadow duration-200` + `hover:shadow-md` (dark elevated)
- Features cards: `transition-all duration-200` + gradient border appears on hover (see Color section)
- No hover states on mobile (touch devices) — CSS `@media (hover: hover)` gate

### Hero Mockup
- Static SVG/CSS composition — no animation by default
- Claude's discretion: lightweight fade-in on page load (opacity 0 → 1, 600ms ease, 200ms delay) if implementation cost is < 15 lines

### Scroll Animations (Claude's Discretion)
- Section reveal: `opacity: 0 → 1, translateY: 20px → 0` on intersection
- Stagger on step cards: 100ms delay between each card
- Implementation: Intersection Observer API or Tailwind `animate-in` (if available) — no external animation library
- Skip animation if `prefers-reduced-motion: reduce`

### Focus States
- All interactive elements: `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background`
- Matches `--shadow-focus: 0 0 0 3px hsl(var(--ring) / 0.45)` token

## Product Mockup Contract

The hero mockup is a stylized SVG/CSS composition representing the audio-to-estimate flow. No real screenshots.

**Composition:**
- Phone frame (dark rounded rect, `border: 1.5px solid hsl(var(--border))`, subtle drop shadow)
- Inside phone: two states shown side-by-side or in sequence
  - State A: audio waveform bars (5-7 vertical bars, animated subtle pulse at `0.5s ease-in-out infinite alternate`, 50% height variation) in `text-primary` color
  - State B: simplified "estimate" card lines (3 horizontal bars at different widths, simulating line items) in `text-muted-foreground`
- Arrow or transition indicator between states (Lucide `ArrowRight` at 16px, `text-primary`)
- Outer glow: `box-shadow: 0 0 60px hsl(var(--primary) / 0.15)` on the phone frame
- Respect `prefers-reduced-motion`: if set, remove the waveform pulse animation

Source: CONTEXT.md D-05 (audio waveform → estimate PDF transition), D-06 (SVG/CSS composition, no screenshots).
