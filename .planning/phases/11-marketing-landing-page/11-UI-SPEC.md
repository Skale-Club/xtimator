## Typography

All sizes use Inter (`--font-inter`). Exactly 4 sizes declared for the landing page surface.

| Role | Size | Weight | Line Height | Tracking | Usage |
|------|------|--------|-------------|----------|-------|
| Body | 16px (1rem) | 400 (normal) | 1.5 | 0 | Section body copy, footer links, subheadlines below heading level |
| Label | 14px (0.875rem) | 500 (medium) | 1.25 | 0 | Step numbers, badge text, nav links, footer copyright |
| Heading | 24px (1.5rem) | 600 (semibold) | 1.2 | -0.01em | Section headings (How It Works, Features), card titles |
| Display | 48px (3rem) desktop / 36px (2.25rem) mobile | 700 (bold) | 1.1 | -0.02em | Hero headline "Professional estimates in 5 minutes." |

Notes:
- Hero subheadline uses Body size (16px) at weight 400, line-height 1.6, color `hsl(var(--muted-foreground))` for de-emphasis
- Step numbers in How It Works use Display-adjacent sizing: 40px, weight 700, color `hsl(var(--primary) / 0.4)` (muted brand accent as decorative numeral)
- All sizes map directly to existing `--font-size-*` tokens in globals.css

## Color

Token system: all colors consumed via `hsl(var(--token))` syntax per globals.css. Always-dark context — `.dark` class active on `<html>` from root layout default.

| Role | HSL Token | Hex Reference | Usage |
|------|-----------|---------------|-------|
| Dominant (60%) | `--background: 240 10% 3.9%` | #09090B | Page background, hero background, section backgrounds |
| Secondary (30%) | `--card: 240 10% 3.9%` + `--border: 240 3.7% 15.9%` | #09090B / #27272A | Card surfaces (How It Works, Features), navbar background (semi-transparent), bottom CTA band |
| Accent (10%) | `--primary: 224 86% 60%` | #406EF1 | See reserved-for list below |
| Secondary blue | `#7FA4F4` (224 86% 72%) | #7FA4F4 | Hero radial glow outer ring, decorative step numerals muted overlay |
| Destructive | `--destructive: 0 62.8% 30.6%` | — | Destructive actions only (not present on landing page) |

**Accent reserved for (explicit list):**
1. "Get Started Free" primary CTA button fill (navbar + hero + bottom CTA band)
2. Hero radial glow — `radial-gradient(ellipse at center, hsl(var(--primary) / 0.25) 0%, hsl(224 86% 72% / 0.08) 45%, transparent 70%)` centered behind headline
3. Hover ring on How It Works cards — `border-color: hsl(var(--primary) / 0.5)` on hover
4. Focus ring on all interactive elements — `--ring: 224 86% 60%` (already established)
5. Step number decorative digits — `hsl(var(--primary) / 0.35)` (ghost weight, decorative only)

Accent is NOT used on: section headings, body copy, footer text, card body content, subheadlines.

### Navbar color specifics
- Background: `hsl(var(--background) / 0.8)` with `backdrop-blur-md` (semi-transparent on scroll)
- Border-bottom: `hsl(var(--border))` — 1px, subtle
- Wordmark text: `hsl(var(--foreground))` weight 700

### Hero radial glow implementation
```
background: radial-gradient(ellipse at 50% 40%, hsl(var(--primary) / 0.25) 0%, hsl(224 86% 72% / 0.08) 45%, transparent 70%);
```
Applied as absolute-positioned div behind headline text, `pointer-events-none`, `w-[800px] h-[600px]` centered, blurred with `blur-3xl`.

## Animation Contract

All animations are CSS-only (Intersection Observer + Tailwind class toggling). No Framer Motion. (Source: CONTEXT.md D-13, D-14)

| Element | Trigger | Animation | Duration | Delay |
|---------|---------|-----------|----------|-------|
| Navbar | Mount | `opacity: 0→1` | 300ms | 0ms |
| Hero headline | Load | `opacity: 0→1, translateY: 8px→0` | 500ms | 0ms |
| Hero subheadline | Load | `opacity: 0→1, translateY: 8px→0` | 500ms | 100ms |
| Hero CTA row | Load | `opacity: 0→1, translateY: 8px→0` | 500ms | 200ms |
| How It Works cards | Scroll (IntersectionObserver, 10% threshold) | `opacity: 0→1, translateY: 16px→0` | 400ms | 0/100/200ms stagger |
| Features cards | Scroll (IntersectionObserver, 10% threshold) | `opacity: 0→1, translateY: 12px→0` | 400ms | 0/80/160/240ms stagger |
| Bottom CTA band | Scroll (IntersectionObserver, 10% threshold) | `opacity: 0→1, translateY: 8px→0` | 400ms | 0ms |

Implementation: `useInView` custom hook or React `useEffect` + `IntersectionObserver`. Initial class `opacity-0 translate-y-4`, toggled to `opacity-100 translate-y-0 transition-all duration-[400ms] ease-out` on intersection.

## Implementation Notes for Executor

1. **No hardcoded app name** — always `getBranding().appName` per D-16. Page component must be `async` to `await getBranding()`.
2. **Never use Framer Motion** — D-13 locks animations to Intersection Observer + Tailwind CSS only.
3. **Radial glow** — Implemented as `absolute` positioned `div` with `pointer-events-none` and Tailwind arbitrary gradient value. Do not use CSS `background` on the section element itself; keep it as a separate layer so text is not affected.
4. **Tailwind arbitrary values** — Follow established pattern from Phase 9: `bg-[hsl(var(--primary)/0.25)]`, not hardcoded hex values.
5. **`100svh` not `100vh`** — Use `svh` units for hero height to avoid iOS Safari viewport chrome overlap (D-07).
6. **Server component first** — `app/page.tsx` must be a server component for `getBranding()` and `getClaims()` calls. Client components scoped to animation hooks only.
7. **Middleware patch** — `proxy.ts` exemption for `/` must be implemented in the same plan as the landing page itself.
8. **Phase 12 readiness** — All user-visible strings must be plain English string literals (not interpolated fragments) so Phase 12's `t()` wrapper can be applied cleanly.
