APPEND to the existing lib/actions/team.ts (do NOT rewrite inviteMember/revokeInvite). Add a `roleSchema = z.enum(['admin','member'])` near the existing `inviteSchema`.

removeMember(companyId: string, userId: string):
1. Gate: `let ctx; try { ctx = await requireCompanyManager(companyId) } catch (e) { return { error: e instanceof XtimatorError ? e.userMessage : 'Not authorized' } }`.
2. `const service = requireServiceClient()`.
3. Look up the target's current role: `service.from('company_members').select('role').eq('company_id', companyId).eq('user_id', userId).maybeSingle()`. No row → `{ error: 'Member not found.' }`.
4. LAST-OWNER GUARD: if `target.role === 'owner'` → `{ error: 'The company owner cannot be removed.' }` (no delete).
5. Delete: `service.from('company_members').delete().eq('company_id', companyId).eq('user_id', userId)`. On error → `{ error: 'Failed to remove member.' }`.
6. `revalidatePath(TEAM_PATH)`; return `{ success: true as const }`.

changeMemberRole(companyId: string, userId: string, role: 'admin' | 'member'):
1. Gate (same try/catch as above).
2. Validate: `const parsed = roleSchema.safeParse(role); if (!parsed.success) return { error: 'Invalid role.' }` — this rejects 'owner'.
3. `const service = requireServiceClient()`.
4. Look up target role (same maybeSingle as removeMember). No row → `{ error: 'Member not found.' }`.
5. OWNER-TARGET GUARD: if `target.role === 'owner'` → `{ error: 'The company owner role cannot be changed.' }` (no update).
6. Update: `service.from('company_members').update({ role: parsed.data }).eq('company_id', companyId).eq('user_id', userId)`. On error → `{ error: 'Failed to update role.' }`.
7. `revalidatePath(TEAM_PATH)`; return `{ success: true as const }`.

Document the scope fence in a comment: NO billing/seat sync here (Phase 139 reads the clean membership change). Do NOT import any billing module.
