  <action>
    1. Install `resend`: `npm install resend`

    2. Add `RESEND_API_KEY=` to `.env.example` (per D-23). If .env.example doesn't exist, create it with all known env vars.

    3. Create `app/api/estimates/[id]/send/route.ts` — POST route per D-14.

    Request body schema:
    ```typescript
    { to: string, subject: string, body: string, attachPdf: boolean }
    ```

    POST handler:
    - Authenticate via `createClient()` + `getClaims()`. Return 401 if no claims.
    - Parse and validate request body. Return 400 if invalid.
    - Fetch estimate context using `getEstimateWithContext(supabase, id)` from estimate.ts. Return 404 if not found.
    - Initialize Resend: `const resend = new Resend(process.env.RESEND_API_KEY)`.
    - Build email:
      - `from`: Use `"EstimateBuilder Pro <onboarding@resend.dev>"` for dev, or `"{companyName} <noreply@{domain}>"` if custom domain configured. For v1 just use `onboarding@resend.dev` as the from address.
      - `to`: from request body
      - `subject`: from request body
      - `html`: Convert the body text to simple HTML (replace newlines with `<br>`), include the share link as a clickable button/link.
    - If `attachPdf` is true:
      - Import `renderToBuffer` from `@react-pdf/renderer` and `EstimatePDF` from `@/components/pdf/estimate-pdf`.
      - Generate PDF buffer server-side.
      - Attach to email as `{ filename: 'Estimate-{projectName}.pdf', content: pdfBuffer }`.
    - Send via `resend.emails.send(...)`.
    - On success:
      - Update estimate: `sent_at = new Date().toISOString()`
      - Update project status to 'sent': `supabase.from('projects').update({ status: 'sent' }).eq('id', projectId)`
      - Log activity: insert `estimate_activity` with event_type 'estimate_sent'.
      - Revalidate the project page.
    - Return `{ success: true }` or `{ error: '...' }` with appropriate status codes.

    4. Add `markAsSentAction` to `lib/actions/estimate.ts` (per D-15, EMAIL-06):
    - Authenticate with getAuthContext().
    - Accept `estimateId: string` parameter.
    - Fetch estimate to get project_id.
    - Update estimate: `sent_at = new Date().toISOString()`.
    - Update project: `status = 'sent'`.
    - Log activity: event_type = 'estimate_marked_sent'.
    - Revalidate project path.
    - Return `{ success: true }`.
  </action>
