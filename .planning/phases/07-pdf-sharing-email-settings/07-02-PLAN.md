    1. Create `lib/queries/share.ts` — query functions using service role client (bypasses RLS per D-06, SEC-02).

    ```typescript
    import { createServiceClient } from '@/lib/supabase/service'

    export interface ShareEstimateData {
      estimate: EstimateWithSections & {
        project: { name: string; project_type: string | null }
        company: {
          name: string; owner_name: string | null; phone: string | null;
          email: string | null; website: string | null;
          address: string | null; city: string | null; state: string | null; zip: string | null;
          logo_url: string | null; brand_primary_color: string | null;
          notify_on_view: boolean; notify_on_accept: boolean; notify_on_decline: boolean;
        }
      }
      client: { name: string; email: string | null; phone: string | null; address: string | null; city: string | null; state: string | null; zip: string | null } | null
    }
    ```

    `getEstimateByShareToken(token: string)` function:
    - Use `createServiceClient()` (service role bypasses RLS).
    - Query: `supabase.from('estimates').select('*').eq('share_token', token).single()`. Return null if not found.
    - Then fetch sections+items using same pattern as `fetchEstimateWithSections` from estimate.ts (copy the logic or import it).
    - Fetch project: `supabase.from('projects').select('name, project_type, client_id, client:clients(name, email, phone, address, city, state, zip)').eq('id', estimate.project_id).single()`
    - Fetch company: `supabase.from('companies').select('name, owner_name, phone, email, website, address, city, state, zip, logo_url, brand_primary_color, notify_on_view, notify_on_accept, notify_on_decline').eq('id', estimate.company_id).single()`
    - Return combined data object or null.

    2. Create `app/estimate/[token]/actions.ts` (server actions, NOT 'use server' at top since these are called from client components — actually DO use 'use server' since Next.js server actions work from client components too).

    `logEstimateView(token: string)`:
    - Use service role client.
    - Look up estimate by share_token. If not found, return.
    - Update `estimates.viewed_at = NOW()` if `viewed_at` is null (first view only for the timestamp).
    - Insert into `estimate_activity`: event_type = 'estimate_viewed', project_id, company_id, estimate_id.
    - Check company notification preferences (notify_on_view). If true and `RESEND_API_KEY` env var exists, send email notification to company email. Use a try/catch — if Resend is not yet installed (Plan 03), just skip silently. Import Resend conditionally: `try { const { Resend } = await import('resend'); ... } catch { /* resend not installed yet */ }`.
    - Email subject: "Your estimate was viewed - {projectName}". Simple text body.

    `respondToEstimate(token: string, response: 'accepted' | 'declined')`:
    - Use service role client.
    - Look up estimate by share_token. Return error if not found or if `client_response` already set (prevent double-response).
    - Update estimate: `client_response = response`, `responded_at = new Date().toISOString()`.
    - Update project status: `supabase.from('projects').update({ status: response }).eq('id', estimate.project_id)`.
    - Insert into `estimate_activity`: event_type = `estimate_${response}`, project_id, company_id, estimate_id.
    - Check company notification prefs (notify_on_accept / notify_on_decline). If enabled, send email via Resend (same conditional import pattern).
    - Return `{ success: true }`.
