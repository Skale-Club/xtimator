Create a compact inline voice recorder component for use inside the refinement panel.

**Key UX requirements:**
- ~30 second cap (maxDurationMs = 30000, not 10 minutes)
- Visual: Mic button, waveform/level indicator, elapsed time counter
- States: idle → recording → transcribing → (success/error handled by parent)
- On stop: immediately transcribe and pass instruction to onRecorded callback

**Implementation:**

1. Props interface:
```typescript
interface VoiceRefineRecorderProps {
  estimateId: string
  onRecorded: (instruction: string) => Promise<void>  // fires after transcription, before refine API
  disabled?: boolean
}
```

2. Internal state: recording | idle, elapsedMs, audioBlob

3. Recording logic (mirrors capture-recorder.tsx patterns):
   - Request microphone: navigator.mediaDevices.getUserMedia({ audio: true })
   - Create MediaRecorder with getSupportedAudioMimeType()
   - Collect chunks into Blob
   - On stop: create audioBlob

4. Duration cap: setTimeout at 30000ms auto-stops recording

5. On recorded callback:
   - Call API with FormData (audio blob)
   - Show transcribing state while waiting for response
   - Return transcript text via resolve

6. UI: Compact row with mic icon button + "Tap to speak" label + elapsed counter
   - Recording state: red pulsing mic, waveform bars, "Tap to stop"
   - Transcribing state: Loader2 spinner, "Transcribing..."

7. Error handling: toast.error on mic permission denied, API failure

8. Mobile-friendly: 44px minimum tap target on mic button

<task type="auto">
  <name>Task 2: Create voice refinement API route</name>
  <files>app/api/estimates/[id]/refine/voice/route.ts</files>
  <action>
Create new API route at /api/estimates/[id]/refine/voice:

**Endpoint: POST /api/estimates/[id]/refine/voice**

**Purpose:** Receives audio blob from VoiceRefineRecorder, transcribes via Whisper, calls refineEstimate pipeline, creates new version.

**Implementation steps:**

1. **Auth check** — same pattern as /api/estimates/[id]/refine: getClaims(), company lookup, 401/403 if missing

2. **Estimate validation** — getEstimateById, check ownership, check is_current (return 400 if old version with clear message)

3. **Parse audio** — Extract audio blob from FormData (field name: 'audio'). Validate it's a real blob (check size > 0, type starts with 'audio/'). Return 400 if missing or invalid.

4. **Transcribe via Whisper** — Use the same pattern as transcribeRecording() in lib/actions/recording.ts:
   - Upload audio to Supabase Storage with service role client
   - Path format: `{companyId}/refine-voice/{estimateId}-{timestamp}.webm`
   - Send to OpenAI Whisper API (fetch to https://api.openai.com/v1/audio/transcriptions)
   - Get transcript text from response
   - Delete storage file after transcription (cleanup)

5. **Call refineEstimate pipeline** — Use the EXACT same logic as /api/estimates/[id]/refine:
   - Fetch current estimate with sections/items
   - Load price book items
   - Build RefineEstimateInput with instruction = transcript
   - Call provider.refineEstimate()
   - Math validation, version management (mark old is_current=false, insert new version+1)
   - Persist sections and items to DB
   - Log estimate_refined activity
   - revalidatePath

6. **Return** — { success: true, newVersion: number, estimateId: string, transcript: string }

**Reuse strategy:** Consider extracting the core refinement logic from /api/estimates/[id]/refine into a shared utility function (e.g., lib/actions/refine-estimate.ts) that both routes call, to avoid duplication.

**Error handling:** Return 400 for missing audio, 500 for transcription failure or refine failure. Log errors to console.
</action>
