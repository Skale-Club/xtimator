Database schema (projects table):
```sql
CREATE TABLE projects (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  client_id UUID REFERENCES clients(id) ON DELETE SET NULL,
  name TEXT NOT NULL,
  project_type TEXT,
  status TEXT NOT NULL DEFAULT 'draft',
  target_budget NUMERIC(12,2),
  total NUMERIC(12,2) DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE TABLE estimate_activity (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  estimate_id UUID REFERENCES estimates(id) ON DELETE SET NULL,
  event_type TEXT NOT NULL,
  metadata JSONB,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

Add import at top: `import type { ProjectFormValues } from '@/lib/schemas/project'`

Add exported function `createProjectAction(formData: ProjectFormValues)`:
1. Call `getAuthContext()`, return `{ error }` if auth fails
2. Destructure `{ supabase, company }`
3. Determine `projectType`: if `formData.projectType === 'Custom'` and `formData.customProjectType` is truthy, use `formData.customProjectType`; otherwise use `formData.projectType`
4. Parse `targetBudget`: if `formData.targetBudget` is truthy, `parseFloat(formData.targetBudget)`, else `null`. If `isNaN`, set to `null`.
5. Insert into `projects` table:
   ```
   { company_id: company.id, client_id: formData.clientId, name: formData.name,
     project_type: projectType, status: 'draft', target_budget: targetBudget, total: 0 }
   ```
   Chain `.select().single()` to get back the created project.
6. If insert error, return `{ error: 'Failed to create project. Please try again.' }`
7. Insert into `estimate_activity`:
   ```
   { project_id: project.id, company_id: company.id, event_type: 'project_created',
     metadata: { project_name: formData.name } }
   ```
8. Call `revalidatePath('/dashboard')`
9. Return `{ data: project }` (per D-04, caller uses project.id for redirect via router.push -- see Pitfall 6 in RESEARCH.md)
