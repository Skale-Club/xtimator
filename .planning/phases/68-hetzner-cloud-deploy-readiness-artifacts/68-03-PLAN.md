<task type="checkpoint:human-action">
  <name>Task 1: Local Docker build + /api/health validation (HETZNER-06)</name>
  <what-built>The artifacts shipped in Plans 68-01 and 68-02 (Dockerfile, docker-compose, /api/health) need to actually run end-to-end against dev Supabase to prove the future Hetzner deploy will work.</what-built>
  <action>
    Open a terminal on the dev machine and run:

    ```bash
    # 1. Confirm Docker Desktop is running
    docker --version
    # Should print: Docker version 24.x or later

    # 2. Build the image (timeout: 5 min)
    docker build -t xtimator:test . 2>&1 | tee .planning/phases/68-hetzner-cloud-deploy-readiness-artifacts/68-docker-validation.txt
    # Expected: BUILD SUCCESS

    # 3. Inspect image size
    docker images xtimator:test --format "{{.Repository}}:{{.Tag}} {{.Size}}" | tee -a .planning/phases/68-hetzner-cloud-deploy-readiness-artifacts/68-docker-validation.txt
    # Expected: under 500MB

    # 4. Run the container in background
    docker run -d --name xtimator-test -p 3000:3000 --env-file .env.local xtimator:test
    sleep 5

    # 5. Hit /api/health
    echo "--- /api/health response ---" >> .planning/phases/68-hetzner-cloud-deploy-readiness-artifacts/68-docker-validation.txt
    curl -s http://localhost:3000/api/health | tee -a .planning/phases/68-hetzner-cloud-deploy-readiness-artifacts/68-docker-validation.txt
    # Expected: {"ok":true,"db":"ok","storage":"ok","commit":"..."}

    # 6. Open http://localhost:3000 in browser
    # Manually verify:
    #   - Landing page loads
    #   - Click "Sign up" → form renders
    #   - (Optional) sign up with throwaway email; confirm onboarding loads

    # 7. Stop and clean up
    docker stop xtimator-test
    docker rm xtimator-test
    ```
