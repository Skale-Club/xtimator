HARD-05: surface per-message batch failures on WhatsApp. The Send fan-out + `mediaResults` reducer already isolate a bad message (one failed item never kills the batch) — the gap is VISIBILITY. The `mediaResults` array is dropped after ingest, so carry a NEUTRAL summary forward on core state and compose ONE aggregated note into the existing reply body. Never-reply invariant preserved (exactly one reply per batch).

Purpose: turns silent partial success into a reported one, per HARD-05.
Output: neutral `droppedInputs` field on EstimateState; ingest summarizes failed items into it; finalize composes one note into both reply bodies via a dedicated `mediaResults` reason→copy map (separate from the frozen `failureReasonToChannelCopy`).
