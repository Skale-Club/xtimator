# Phase 1001: External SEO Setup

These steps require the production owner’s account or DNS access and cannot be
completed from the repository.

## Google Search Console

- Verify `xtimator.com` as a Domain property using the DNS record provided by
  Search Console.
- Submit `https://xtimator.com/sitemap.xml`.
- Inspect `https://xtimator.com/` and
  `https://xtimator.com/industries/general-contractors` after deployment.

## Meta Sharing Debugger

- Rescrape `https://xtimator.com/` and one published industry or blog URL.
- Confirm `og:url`, `og:type`, image, title, and description are populated.
- Leave `fb:app_id` absent unless Xtimator owns a real Facebook App ID.
