**The 11 rewritten values** (from `CONTEXT.md`, confirmed by Plan 03's summary):
`companies.logo_url` 1 → `logos` bucket; `platform_branding.logo_url` 1,
`platform_branding.og_image_url` 1 → `platform-brand`; and **8 inside
`platform_branding.landing_content`** → `platform-brand` (hero image, hero
background image, hero background **video**, step images, feature images).

Two consequences that shape this plan:

1. **Every rewritten value lands in a PUBLIC bucket** (`logos` or
   `platform-brand`). There are zero rewritten values in `photos`/`audio`/`pdfs`.
   So the tenant-gate behavior has **no subject in this batch** — record that as
   a fact, do not plan a verification with nothing to verify.
2. **One of the 8 is a video**, not an image. An image-only verification would
   miss it, and it is the value that exercises `media-src` rather than `img-src`.

Proxy behavior per bucket (`lib/storage/proxy-policy.ts`, shipped Phase 187):

| bucket | access | Cache-Control |
|---|---|---|
| `platform-brand` | public, no auth | `public, max-age=31536000, immutable` |
| `logos` | public, no auth | `public, max-age=300, stale-while-revalidate=86400` |
| `photos`, `audio`, `pdfs` | tenant-gated | `private, no-store` + `Vary: Cookie` |

**`company_price_book.image_url` is EXCLUDED and has no subject here.** It holds
293 non-null rows, all external `https://images.pexels.com/...` stock photos, and
**zero** Supabase URLs — nothing was rewritten there. Its writers do call
`getPublicUrl('photos', …)` and `photos` is `public = false`, so such a value
*would* be broken if one existed; none does. Record the exclusion and the 293/0
numbers; do not build a verification for a case with no data.

**CSP.** `next.config.ts` ships a **report-only** policy with
`img-src 'self' data: blob: https://*.supabase.co https://*.googleusercontent.com`
and `media-src 'self' blob: https://*.supabase.co`, and a collector at
`/api/csp-report`. `'self'` covers the new same-origin `/storage/...` form for
both directives — including the background video under `media-src`. Verify no new
violation appears; narrowing the policy is Phase 190's URL-04, not this plan's.

Surfaces to probe:
- App UI (authenticated): company logo in topbar/sidebar.
- Public share page (anonymous): `https://xtimator.com/estimate/{token}`.
- PDF: `GET https://xtimator.com/api/estimates/{id}/pdf`.
- Landing / branding: `https://xtimator.com/` — platform logo, OG image, hero,
  hero background image + video, step and feature images.

Evidence goes to the scratchpad, never the repo — it contains tenant identifiers.

  <action>

     Cloudflare cache analysis.
6. Produce the 11-row table (path, bucket, status, content-type, bytes) for the
   summary. "11/11 OK" with the table beneath it is the acceptable evidence
   format; "N rows updated" is not.

   bucket, so the proxy's ownership gate has no subject in this batch.
  </action>
