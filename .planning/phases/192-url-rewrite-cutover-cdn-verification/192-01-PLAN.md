The live route this plan targets (`app/storage/[bucket]/[...key]/route.ts`):
`GET /storage/{bucket}/{key}` — `{key}` is a catch-all segment array; Next.js
decodes each segment before `normalizeProxyKey` sees it, and any segment
containing `/`, `\`, NUL, `.` or `..` is refused. The emitter written here must
therefore percent-encode **each key segment individually** and join with `/`.

Shape of the URLs being rewritten (from `lib/storage/supabase-provider.ts`
`getPublicUrl`, persisted in DB rows since Phase 1):
```
https://prmqgcrnpuvpzruyzvuv.supabase.co/storage/v1/object/public/{bucket}/{key}
```

**Measured production scope (direct query, 2026-08-06 - see `CONTEXT.md`): 11
occurrences across 4 columns.** `companies.logo_url` 1, `platform_branding.logo_url`
1, `platform_branding.og_image_url` 1, `platform_branding.landing_content` 8 (one
3,050-byte JSONB document). Everything else measured zero. This is small enough
that every rewritten value is verified individually later in the phase - so build
for exactness, not for throughput. No batching, windowing, streaming or

The table is the URL-02 "reversible record". It must be concrete enough that a
restore is a data operation, not a reconstruction:

```sql
create table if not exists public.storage_url_rewrites (
  id           bigint generated always as identity primary key,
  batch_id     uuid        not null,
  target       text        not null,   -- 'companies.logo_url', 'auth.users.user_metadata'
  row_pk       text        not null,   -- pk rendered as text ('1' for the platform_branding singleton)
  value_kind   text        not null check (value_kind in ('text','jsonb','user_metadata')),
  old_value    jsonb       not null,   -- FULL previous value (whole doc for jsonb/user_metadata)
  new_value    jsonb       not null,   -- FULL new value, so revert can detect drift
  rewritten_at timestamptz not null default now(),
  reverted_at  timestamptz
);
```

Design points that are load-bearing — do not "simplify" them away:

- `old_value`/`new_value` are **jsonb**, not text, so a scalar TEXT column and a
  whole JSONB document (`platform_branding.landing_content`) and a whole
  `auth.users.user_metadata` object all record identically. A scalar is stored
  as a JSON string.
- Storing the **whole** document for jsonb/user_metadata targets (not a
  per-field patch) is what makes restore exact and single-statement.
- `new_value` exists so the revert can refuse to clobber a row that changed
  after the rewrite (someone re-uploaded a logo). Plan 02 implements that check.

Add:
- `create index if not exists storage_url_rewrites_batch_idx on public.storage_url_rewrites (batch_id);`
- `create unique index if not exists storage_url_rewrites_batch_row_uniq on public.storage_url_rewrites (batch_id, target, row_pk);` — one record per row per batch, so a re-run inside the same batch cannot double-record.
- `alter table public.storage_url_rewrites enable row level security;` with **no policies**, matching the `platform_integrations` convention in `20260419000001_platform_admin.sql` (deny-all for anon/authenticated; service role bypasses).
- `comment on table` stating: this is the URL-02 reversible record for the

  <action>
Create `lib/storage/url-rewrite.ts`. It must be **pure**: no `import 'server-only'`,
no env reads, no I/O — the same discipline `lib/storage/proxy-policy.ts` states in
its header, so it is importable from unit tests, from `scripts/` under plain
`tsx`, and from server code.

Exports:

```typescript
export interface ParsedStorageUrl { bucket: ProxyBucket; key: string }
export function parseSupabasePublicUrl(value: string): ParsedStorageUrl | null
export function toProxyPath(bucket: ProxyBucket, key: string): string
export function rewriteAssetUrl(value: unknown): { changed: boolean; value: unknown }
export function rewriteJsonAssetUrls(doc: unknown): { changed: number; value: unknown }
```

Rules:

1. **Import the allowlist** — `isProxyBucket` from `@/lib/storage/proxy-policy`.
   Do not redeclare the five bucket names here. A sixth bucket must be a
   one-place change.
2. Parse with the `URL` constructor inside a try/catch, not a hand-rolled regex
   over the whole string. Require: `protocol === 'https:'`, hostname matching
   `/^[a-z0-9-]+\.supabase\.(co|in)$/`, pathname starting with
   `/storage/v1/object/public/`. Anything else → `null`.
3. Reject when `url.search` or `url.hash` is non-empty — a public URL carrying a
   query is not the plain persisted form and must be left alone rather than
   silently truncated.
4. Split the remaining pathname, `decodeURIComponent` each segment; first segment
   is the bucket, the rest joined with `/` is the key. Empty key → `null`.
5. `toProxyPath` percent-encodes **each key segment individually**
   (`encodeURIComponent`) and joins with `/`, prefixed `/storage/{bucket}/`.
   This is what keeps the output legal for `normalizeProxyKey`.
6. `rewriteAssetUrl` returns `{ changed: false, value }` unchanged for anything
   that is not a string, or that already starts with `/storage/`, or whose parse
   returns `null`. **Never throw** — a bad row must be skipped, not crash a
   production rewrite mid-flight.
7. `rewriteJsonAssetUrls` recurses over arrays and plain objects, applying
   `rewriteAssetUrl` to every string leaf **individually** (value-level, not a
   document-level substitution), and returns a new document (structural copy)
   plus the count of changed leaves. It is deliberately **key-agnostic**:
   `platform_branding.landing_content` in production is a single 3,050-byte
   document holding **exactly 8** Supabase storage URLs (hero image, hero
   background image, hero background **video**, step images, feature images -
   measured 2026-08-06), and enumerating those field paths would rot the moment
   the landing editor adds a field. One of the 8 is a video, so the walk must not
   special-case images. Only strings that parse as a Supabase public storage URL
   for an allowlisted bucket are ever touched.
8. Guard against pathological nesting with a depth cap (e.g. 32) — exceeding it
   returns the subtree untouched rather than recursing forever.

Header comment must state: this module is the URL-02 translation layer; the
inverse operation is not a code path but the `storage_url_rewrites` table.
