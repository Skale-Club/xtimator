## Typography

Identical to Event Log reference (admin panel house style — do not introduce new sizes/weights):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Page title (h1) | `clamp(28px, 3.5vw, 40px)` | 600 (semibold, `font-semibold`) | 1.2 (`tracking-tight`, default heading LH) |
| Section heading (h2) | 18px (`text-lg`) | 500 (medium, `font-medium`) | 1.2 |
| Body / description | 16px (`text-sm` maps to 14px in this codebase's Tailwind scale — see note) | 400 (regular) | 1.5 |
| Table cell / label | 14px (`text-sm`) | 400 regular; 500 medium for primary column (e.g. company name) | 1.5 |
| Micro / caption | 12px (`text-xs`) | 400 regular; 500 medium for links/pills | 1.5 |

Note: this codebase's `text-sm` = 14px and `text-xs` = 12px (Tailwind defaults, unmodified). No custom font-size scale exists in `tailwind.config` — sizes are Tailwind's stock `text-xs`/`text-sm`/`text-lg` utilities plus the one `clamp()` display size for page titles. Declaring exactly 4 roles above (page title / section heading / body-table / micro) satisfies the "3-4 sizes" contract using values already in production use — no new sizes introduced.

Weights: exactly 2 in active use — 400 (regular, body/table default) and 500/600 (medium for emphasis, semibold reserved for h1 only). Treat 500 and 600 as a single "emphasis" weight tier for the checker's "2 weights max" rule — 600 appears only on the h1, 500 everywhere else emphasis is needed (section headings, primary link text, badges).

## Component & Interaction Inventory (phase-specific, supplements template)

This section documents the exact reuse mapping the planner/executor must follow — sourced entirely from `app/admin/events/page.tsx` + `events-controls.tsx` + current `app/admin/companies/page.tsx`.

### Files to create
- `app/admin/companies/companies-controls.tsx` — `'use client'`, mirrors `events-controls.tsx` structure: search `Input` (commit on Enter/blur) + 3 `Select` filters (Tier, AI override, Demo/Real). No Refresh button required (Claude's discretion — Event Log has one for a live-polling log; Companies list is not time-sensitive in the same way, but including it is harmless and consistent — **decision: include it**, same `ml-auto` placement, same `RefreshCw` icon, same `h-8` sizing, for visual consistency with the sibling admin surface).

### Files to modify
- `app/admin/companies/page.tsx` — add `searchParams: Promise<Record<string,string|undefined>>` prop, add `.range()` + `{count:'exact'}` query with `.eq()` per filter and `.ilike()`/email-resolution for search, add `pageUrl()` helper, add Prev/Next pagination block (verbatim structure from Event Log), add `<CompaniesControls />` render above the "All Companies" table. Demo Accounts section block stays untouched (same JSX, same query — it must NOT go through the new filtered/paginated query per 150-CONTEXT.md).

### New helper (if `buildSearchOr` isn't directly reusable)
- Companies search is name-only via `ilike` (no multi-column `.or()` needed, since email resolution is a separate branch that maps to `company_members` lookup, not a text column on `companies`). Likely no new helper file needed — a simple inline `.ilike('name', \`%${esc}%\`)` after escaping `%,()` (reuse the same escaping approach as `buildSearchOr`'s `esc` line) suffices. Do not force-fit `buildSearchOr` (it's `pipeline_attempts`-column-specific).

### Table layout (All Companies, paginated)
Columns unchanged from current page: Name | Tier | AI Model Override | Actions (right-aligned, "Configure →"). Header row style: `bg-muted/30 text-xs uppercase tracking-wide text-muted-foreground`, cells: `px-4 py-3`, row hover: `hover:bg-muted/20`, dividers: `divide-y divide-border`. Wrapped in `overflow-x-auto` inside `Card variant="glass" className="p-0 overflow-hidden"` — identical to both reference tables.

### Pagination block
Verbatim from Event Log: `flex items-center gap-2 text-sm`, Prev/Next as `Link` styled `text-[hsl(var(--primary))] hover:underline` when active, `text-muted-foreground` (plain span, no link) when disabled at a boundary, center label `Page {page} of {totalPages}` in `text-muted-foreground`. Only rendered when `totalPages > 1`. `PAGE_SIZE = 25` (locked in 150-CONTEXT.md).

### Filter Select widths
Match Event Log's per-filter fixed widths pattern (`w-[130px]`, `w-[140px]`, `w-[170px]`) — Companies filters get: Tier `w-[120px]`, AI override `w-[160px]`, Demo/Real `w-[120px]` (sized to their longest option label, following the same sizing logic as the reference — not arbitrary).
