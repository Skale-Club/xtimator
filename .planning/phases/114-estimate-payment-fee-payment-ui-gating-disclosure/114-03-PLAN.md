<objective>
Disclose the platform fee at the Stripe connection moment (DISCLOSE-01). In the `not_connected`
branch of `StripeConnectCard`, render a clear notice: "Xtimator charges a {X}% fee on each payment
you receive — separate from Stripe's processing fees." `{X}` is the LIVE `estimateFeePct` read
server-side in `app/(app)/settings/payments/page.tsx` via `getBillingConfig()` and passed into the
card as a `feePct` prop, formatted as `feePct × 100` — so the disclosed % can never diverge from the
% actually charged (FEE-03) and is never a hard-coded "1%" string in JSX.

Purpose: transparency-as-feature — the owner learns the fee in OUR flow, not by discovering it later
in their Stripe dashboard. Lock the disclosed value to `billing_config` so one number drives both the
charge and the disclosure.
Output: the `feePct` prop + disclosure block on the card, the server-side config read on the page,
and a dedicated test proving the rendered % is config-driven (mock → 0.02 → "2%"), not hard-coded.

SCOPE: disclosure only. Do NOT touch the fee computation (114-01) or the gating predicate (114-02)
beyond reading their already-shipped values. This plan only adds a `feePct` prop + a JSX disclosure
block + a server config read + one test file.
</objective>
