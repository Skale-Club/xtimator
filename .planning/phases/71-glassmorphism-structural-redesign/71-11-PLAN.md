# Phase 71 — Plan 11: Landing + Auth Premium Polish Pass

**Goal:** Push the two first-impression surfaces (public landing + auth pages) beyond the baseline Phase 71 glassmorphism redesign so they feel as premium as a Stripe Dashboard hero shot. Same token system, same primitive variants, but visually more striking since these are the first thing a prospective customer sees.

**Depends on:** Plans 71-03 (marketing baseline) and 71-04 (auth baseline) — both shipped. This plan composes on top, no rework.

**Scope discipline:** Surface-level composition only. **Zero changes to `components/ui/*` primitives.** Zero functional changes (server actions, form validation, auth logic intact). Zero copy changes to existing strings (new placeholder copy is centralized as i18n-ready constants).

**Why this exists as a separate plan:** The user reviewed the baseline 71-03/71-04 redesign and requested a stronger visual statement on the first-impression surfaces. Rather than mutating 71-03/71-04 retroactively, this captures the upgrade as a discrete, traceable plan.
