<objective>
Build the CUST-02 send primitive: a dedicated-Messaging-Service SMS sender, kept structurally separate from the shared owner-notification `fromPhone` (`lib/sms/client.ts`'s existing `sendSms()`), plus the admin-panel field to configure it — never an env var, per this codebase's platform_integrations convention.

Purpose: Research (176-RESEARCH.md, Toll-Free/A2P section) and the locked milestone decision both require end-customer SMS to ride a number/Messaging Service separate from the shared owner number 6 apps already use — mixing traffic classes risks carrier reputation blast-radius across every app on that number. "Falls back to DISABLED when unconfigured, never to the shared number" is the safety property that makes this separation real rather than aspirational.
Output: `getTwilioCustomerMessagingConfig()`, `sendCustomerSms()`, and an admin-panel field to set the SID — end to end, a tenant with the feature unconfigured gets a clean refusal, never a silent reroute.
</objective>
