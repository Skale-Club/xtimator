<interfaces>
From lib/storage/server.ts (built by Plan 01):
```typescript
export type StorageBackend = 'r2' | 'supabase'
export function serverStorageBackend(): StorageBackend
export function getServerStorage(): StorageProvider                     // Supabase mode -> service-role client
export function serverStorage(client: SupabaseClient): StorageProvider  // Supabase mode -> the client you pass
```

`serverStorage(client)` is a drop-in for `createStorage(client)`: same `StorageProvider` interface, same synchronous signature, same return type. In Supabase mode it delegates to the client you hand it — so a user-scoped client keeps its `storage.objects` RLS scoping exactly as today.

Still in `@/lib/storage` and unchanged: `buildStorageKey`, all types, and `createStorage` (now meaning "explicitly Supabase").
