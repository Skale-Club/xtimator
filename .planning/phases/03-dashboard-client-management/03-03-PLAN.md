      ```typescript
      const supabase = await createClient()
      const { data: claimsData } = await supabase.auth.getClaims()
      const claims = claimsData?.claims ?? null
      if (!claims) redirect('/auth/login')
      const { data: company } = await supabase.from('companies').select('id').eq('user_id', claims.sub).single()
      if (!company) redirect('/onboarding')
      ```
    - Fetch: `const clients = await getClients(supabase, company.id)`
    - Render:

    **2. Create ClientList** (`components/clients/client-list.tsx` — per D-16, CLIENT-01, CLIENT-06, D-22, D-23):
    - "use client" component
    - Accept props: `{ clients: ClientWithCount[]; companyId: string }`
    - **State:**
      - `search: string` (default '')
      - `sheetOpen: boolean` (default false)
      - `editingClient: ClientDetail | null` (default null)
      - `deleteDialogOpen: boolean` (default false)
      - `deletingClient: { id: string; name: string; projectCount: number } | null`
    - **Search**: shadcn/ui `Input` with Search icon, filters clients by name, email, or phone (case-insensitive)
    - **Filtered list**: `useMemo` filtering by search
    - **Rendering:**
      - If `clients.length === 0`: `<EmptyState icon={Users} title="No clients yet" description="Add your first client to get started" actionLabel="Add Client" />` with onClick opening the sheet (per D-22)
      - If filtered empty but clients exist: `<EmptyState icon={Search} title="No clients match your search" description="Try a different search term" onClearFilter={() => setSearch('')} />`
      - Otherwise: Render a list/table. Each row shows:
        - Avatar (client logo_url or first letter of name as fallback)
        - Client name (linked to `/clients/${client.id}`)
        - Email (`text-muted-foreground`, or '---')
        - Phone (`text-muted-foreground`, or '---')
        - Project count badge
        - Actions: DropdownMenu with "View" (Link to /clients/[id]), "Edit" (opens sheet with client data), "Delete" (opens AlertDialog)
      - Desktop: shadcn/ui `Table` with columns (Name, Email, Phone, Projects, Actions) — `hidden md:block`
      - Mobile: Card list with name + email + project count — `md:hidden`
    - **Add Client button**: Also opens the sheet with `editingClient = null` for create mode
    - **Edit handler**: Fetch full client data when edit is clicked. Use browser Supabase client directly (no server action needed for reads — RLS handles it).
    - **Delete flow** (per D-20, CLIENT-06):
      - AlertDialog with title "Delete Client"
      - If `deletingClient.projectCount > 0`: description `"${name}" has ${projectCount} project(s). Deleting will remove the client association from those projects. This action cannot be undone.`
      - If 0 projects: `Are you sure you want to delete "${name}"? This action cannot be undone.`
      - Cancel and Delete (variant="destructive") buttons
      - On confirm: call `deleteClientAction(clientId)`, toast success/error, close dialog
      - Use `useTransition` for pending state
    - **Sheet open/close**: when "Add Client" is clicked, set `editingClient = null`, `sheetOpen = true`. When "Edit" is clicked, fetch client data, set `editingClient = data`, `sheetOpen = true`. ClientSheet receives `editingClient` and `companyId`.

    - Accept props: `{ open: boolean; onOpenChange: (open: boolean) => void; client: ClientDetail | null; companyId: string }`
    - When `client` is null: create mode (title "Add Client"). When `client` is provided: edit mode (title "Edit Client")
    - Uses shadcn/ui `Sheet`, `SheetContent` (side="right"), `SheetHeader`, `SheetTitle`, `SheetDescription`

      - **Logo upload section**: `<ClientLogoUploader>` at top. State: `logoFile: File | null`, `logoPreview: string | null`. Initialize preview from `client?.logo_url` in edit mode.
      - **Name** (required): `<FormField>` with `<Input placeholder="Client name" />`
      - **Email**: `<FormField>` with `<Input type="email" placeholder="Email address" />`
      - **Phone**: `<FormField>` with `<Input placeholder="Phone number" />`
      - **Address**: `<FormField>` with `<Input placeholder="Street address" />`
      - **City**: `<FormField>` with `<Input placeholder="City" />`
      - **State**: `<FormField>` with `<Input placeholder="State" />`
      - **Zip**: `<FormField>` with `<Input placeholder="ZIP code" />`
      - **Notes**: `<FormField>` with `<Textarea placeholder="Notes..." />`
    - Use `Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormMessage` from shadcn/ui form components for inline validation messages (UX-06)
    - **On submit**:
      1. If `logoFile` exists, upload to Supabase Storage:
         - Import `createClient` from `@/lib/supabase/client` (browser client)
         - Upload: `supabase.storage.from('logos').upload(path, file, { upsert: true })`
         - Get public URL: `supabase.storage.from('logos').getPublicUrl(path).data.publicUrl`
      2. Create mode: call `createClientAction(values)` -> get client ID -> if logoFile, upload to `{companyId}/clients/{clientId}/logo.{ext}` -> call `updateClientAction(clientId, { ...values })` with logo_url set
      3. Edit mode: if logoFile, upload to `{companyId}/clients/{client.id}/logo.{ext}` -> call `updateClientAction(client.id, values)` with logo_url
      4. Toast success: `toast.success('Client created')` or `toast.success('Client updated')`
      5. Toast error on failure
      6. Close sheet on success: `onOpenChange(false)`
    - Reset form when `client` prop changes (use `useEffect` to call `form.reset(...)` with client values or defaults)

        - If projects: responsive table/card pattern. Each row: name (linked), type, status badge, total, date.
