    **1. Create dashboard queries** (`lib/queries/dashboard.ts`):
    - Import `SupabaseClient` from `@supabase/supabase-js`
    - Export `DashboardStats` interface: `{ totalProjects: number; pendingEstimates: number; acceptedEstimates: number; totalRevenue: number }`
    - Export `ProjectWithClient` interface: `{ id: string; name: string; project_type: string | null; status: string; total: number; created_at: string; client: { id: string; name: string } | null }`
    - Export async function `getDashboardStats(supabase: SupabaseClient, companyId: string): Promise<DashboardStats>`:
      - Query `projects` count with `.select('*', { count: 'exact', head: true }).eq('company_id', companyId)` -> totalProjects
      - Query `estimates` count with `.eq('company_id', companyId).eq('is_current', true).in('status', ['draft', 'sent'])` -> pendingEstimates
      - Query `estimates` count with `.eq('company_id', companyId).eq('is_current', true).eq('client_response', 'accepted')` -> acceptedEstimates
      - Query `estimates` `.select('total').eq('company_id', companyId).eq('is_current', true).eq('client_response', 'accepted')` then reduce sum -> totalRevenue
      - Return all four with `?? 0` fallbacks
    - Export async function `getProjects(supabase: SupabaseClient, companyId: string): Promise<ProjectWithClient[]>`:
      - Query: `.from('projects').select('id, name, project_type, status, total, created_at, client:clients(id, name)').eq('company_id', companyId).order('created_at', { ascending: false })`
      - Return `data ?? []`, casting total to number

    **2. Create client queries** (`lib/queries/clients.ts`):
    - Import `SupabaseClient` from `@supabase/supabase-js`
    - Export `ClientWithCount` interface: `{ id: string; name: string; email: string | null; phone: string | null; logo_url: string | null; created_at: string; project_count: number }`
    - Export `ClientDetail` interface: extends ClientWithCount with `address, city, state, zip, notes` (all `string | null`)
    - Export async function `getClients(supabase: SupabaseClient, companyId: string): Promise<ClientWithCount[]>`:
      - Query: `.from('clients').select('id, name, email, phone, logo_url, created_at').eq('company_id', companyId).order('name')`
      - For each client, get project count: `.from('projects').select('*', { count: 'exact', head: true }).eq('client_id', client.id)` — OR use a single query approach if Supabase supports it
      - A simpler approach: fetch all clients, then do a single query `from('projects').select('client_id').eq('company_id', companyId)` and count in JS
    - Export async function `getClientById(supabase: SupabaseClient, clientId: string): Promise<ClientDetail | null>`:
      - Query: `.from('clients').select('*').eq('id', clientId).single()`
      - Then get project count for that client
    - Export async function `getClientProjects(supabase: SupabaseClient, clientId: string)`:
      - Query: `.from('projects').select('id, name, project_type, status, total, created_at').eq('client_id', clientId).order('created_at', { ascending: false })`

    **3. Create client zod schema** (`lib/schemas/client.ts`):
    - Import `z` from `zod`
    - Export `clientSchema = z.object({...})`:
      - `name`: `z.string().min(1, 'Client name is required')`
      - `email`: `z.string().email('Invalid email').optional().or(z.literal(''))`
      - `phone`: `z.string().optional().or(z.literal(''))`
      - `address`: `z.string().optional().or(z.literal(''))`
      - `city`: `z.string().optional().or(z.literal(''))`
      - `state`: `z.string().optional().or(z.literal(''))`
      - `zip`: `z.string().optional().or(z.literal(''))`
      - `notes`: `z.string().optional().or(z.literal(''))`
    - Export `type ClientFormValues = z.infer<typeof clientSchema>`
    - Use the `.optional().or(z.literal(''))` pattern established in Phase 2 (STATE.md decision)

    **4. Create client server actions** (`lib/actions/client.ts`):
    - `'use server'` directive
    - Import `createClient` from `@/lib/supabase/server`, `revalidatePath` from `next/cache`
    - Import `ClientFormValues` from `@/lib/schemas/client`
    - All actions follow the getClaims() pattern from lib/actions/company.ts:
      ```
      const supabase = await createClient()
      const { data: claimsData } = await supabase.auth.getClaims()
      const claims = claimsData?.claims ?? null
      if (!claims) return { error: 'Not authenticated' }
      const { data: company } = await supabase.from('companies').select('id').eq('user_id', claims.sub).single()
      if (!company) return { error: 'No company found' }
      ```
    - `createClientAction(formData: ClientFormValues)`: INSERT into clients with company_id, revalidatePath('/clients'), return `{ data: client }`
    - `updateClientAction(clientId: string, formData: ClientFormValues)`: UPDATE clients SET ... WHERE id = clientId, revalidatePath('/clients'), revalidatePath(`/clients/${clientId}`), return `{ data: client }`
    - `deleteClientAction(clientId: string)`: First count projects with client_id = clientId. DELETE from clients WHERE id = clientId. revalidatePath('/clients'). Return `{ data: { deleted: true, orphanedProjects: count } }`

    **5. Create project server actions** (`lib/actions/project.ts`):
    - `'use server'` directive
    - Same getClaims() + company fetch pattern
    - `deleteProjectAction(projectId: string)`: DELETE from projects WHERE id = projectId. revalidatePath('/dashboard'). Return `{ data: { deleted: true } }`
    - `duplicateProjectAction(projectId: string)`: SELECT the project row, INSERT a copy with `name: originalName + ' (Copy)'`, `status: 'draft'`, `total: 0`, new created_at. revalidatePath('/dashboard'). Return `{ data: newProject }`
