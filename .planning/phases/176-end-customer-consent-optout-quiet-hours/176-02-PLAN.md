<interfaces>
Twilio's signature algorithm (verified mechanics, HIGH confidence per research — this is NOT ambiguous, implement exactly):
1. Take the full webhook URL Twilio POSTed to (scheme + host + path + query string, byte-exact match to what's configured in the Twilio Console — 176-05 owns getting this URL right in production behind the Coolify reverse proxy; this plan's function just takes `url: string` as a parameter, it does not resolve it).
2. Take every POST parameter (form-decoded key/value pairs — NOT the raw urlencoded body).
3. Sort parameter names alphabetically (by key).
4. For each key in sorted order, append `key + value` to the URL string with NO delimiter between pairs and NO delimiter between the URL and the first pair.
5. HMAC-SHA1 the resulting string, keyed with the Twilio Auth Token.
6. Base64-encode the digest. Compare (timing-safe) against the `X-Twilio-Signature` header value.

Function signature:
```ts
// lib/sms/verify-webhook.ts
export function verifyTwilioSignature(
  url: string,
  params: Record<string, string>,
  signature: string | null,
  authToken: string,
): boolean
```
Use `timingSafeEqual` (matches `lib/whatsapp/verify.ts`'s existing precedent) — wrap in try/catch since it throws on length mismatch (same pattern as `lib/whatsapp/verify.ts` line 19-24).

Twilio's own DEFAULT keyword set (HIGH confidence, from Twilio's official Advanced Opt-Out docs, per research Q1) — use EXACTLY this list, case-insensitive, trimmed of surrounding whitespace/punctuation, no partial/fuzzy matching (Operational Decision #4 — "auto-suppress on the enumerated keyword list only... log-but-don't-auto-suppress any other inbound reply"):
- stop-class (opt-out): STOP, STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT, REVOKE, OPTOUT
- start-class (opt-in): START, YES, UNSTOP
- help-class: HELP
- anything else (including multi-word bodies, or a keyword embedded in a longer sentence): `'other'`

```ts
// lib/sms/inbound-keywords.ts
export type InboundKeywordType = 'stop' | 'start' | 'help' | 'other'
export function classifyInboundKeyword(body: string): InboundKeywordType
```
"Punctuation-stripped exact match" means: trim whitespace, strip trailing punctuation (e.g. "STOP." or "STOP!"), uppercase, then exact-match against the keyword sets above. A body like "please STOP texting me" is `'other'` (not a bare keyword) — Operational Decision #4 explicitly rejects sentence-embedded/NLP matching; only Twilio's own bare-keyword convention is honored.
