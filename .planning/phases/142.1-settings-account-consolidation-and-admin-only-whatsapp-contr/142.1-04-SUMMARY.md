## Decisions Made

- Fixed PAGE_SIZE=50 with `Math.max(1, Math.ceil(total / PAGE_SIZE))` ensures pageCount≥1 even for zero results
- Sender filter resolves company_id via authorized_senders table then narrows conversations (avoids cross-table join complexity)
- Company and sender labels fetched via `.in('id', [...])` only for result IDs (not all companies) — avoids overfetch
- expectedCompanyId is optional (backward-compatible) but verified when provided — defense-in-depth against stale rows
- Filter controls use the same URL-param-reset-page pattern as the events page (established pattern reuse)
