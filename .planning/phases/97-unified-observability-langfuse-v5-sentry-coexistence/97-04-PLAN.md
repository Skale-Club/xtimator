Key facts:
- lib/ai/providers/openrouter.ts uses raw fetch (not @langchain/* model classes) — confirmed by codebase read. CallbackHandler on graph.invoke does NOT auto-capture these raw-fetch calls. They need explicit @langfuse/tracing instrumentation.
- lib/ai/openrouter-client.ts uses raw fetch for Whisper transcription, vision analysis, translation. Same applies.
- @langfuse/tracing Langfuse class API: `new Langfuse({publicKey, secretKey, baseUrl})` → `lf.generation({name, model, input, startTime})` → `gen.end({output, endTime})` → `await lf.flushAsync()`. Similar to v3 but uses OTel trace context.
- Safe-metadata applies to @langfuse/tracing calls too: only IDs in trace `metadata` or `userId`. No transcript content, audio, API keys.
- The @langfuse/tracing Langfuse singleton: create once per module (module-level `const lf = new Langfuse(...)`) with no-op guard when keys are absent.
</context>

  <action>
Replace the entire contents of `lib/observability/langfuse.ts`. The current file exports `getLangfuse()` using the v3 `langfuse` package. Replace it with a v5 Langfuse client from `@langfuse/tracing` that the migration callers (openrouter-client.ts and openrouter.ts) can import directly.

```typescript
/**
 * lib/observability/langfuse.ts — Phase 97 (OBS-02)
 *
 * Langfuse v5 tracing client for raw-fetch AI call sites that are NOT captured
 * by the @langfuse/langchain CallbackHandler (Whisper transcription, OpenRouter
 * vision, OpenRouter translation, OpenRouterAdapter.callTool).
 *
 * The graph-based estimate generation IS captured automatically by the
 * CallbackHandler attached at graph.invoke in Wave 3.
 *
 * SECURITY: No key literals. Keys read from process.env only.
 * NEVER commit LANGFUSE_PUBLIC_KEY, LANGFUSE_SECRET_KEY, or LANGFUSE_BASEURL.
 */
import 'server-only'
import { Langfuse } from '@langfuse/tracing'

/**
 * Module-level v5 Langfuse client for manual generation spans.
 * Gracefully no-ops when keys are absent — the Langfuse class handles this.
 * Exported directly so callers use `langfuseClient.generation(...)` without
 * the legacy getLangfuse() pattern.
 */
export const langfuseClient = new Langfuse({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY ?? '',
  secretKey: process.env.LANGFUSE_SECRET_KEY ?? '',
  baseUrl: process.env.LANGFUSE_BASEURL ?? 'https://cloud.langfuse.com',
})
```

Note: The old `getLangfuse(): Langfuse | null` export is intentionally removed. All call sites that used `getLangfuse()` are updated in Tasks 2 and 3 of this plan to import `langfuseClient` directly.
