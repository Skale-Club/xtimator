## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 500 (medium) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.15 |

- **Display** is used only for the "EstimateBuilder Pro" wordmark above the card (matches auth pages).
- **Heading** is used for the step title inside the card (e.g., "Business Information", "Brand Identity", "Address & Defaults").
- **Label** is used for form field labels and industry card labels.
- **Body** is used for helper text, descriptions, and form inputs.

## Layout Contract

### Page Structure

```
Full viewport height, centered vertically and horizontally
bg-muted/40 background (matches auth pages)

[Logo SVG + "EstimateBuilder Pro" wordmark]  ← 48px margin-bottom
[Wizard Card max-w-[600px] w-full]
  [StepIndicator — top of card]              ← 24px padding-bottom
  [Separator]
  [Step Content — scrollable if needed]       ← 24px padding all sides
  [Separator]
  [Navigation Footer]                         ← 24px padding, flex justify-between
    [Back button — ghost variant]  [Next/Complete — default variant]
[Skip for now — text link, centered below card] ← 16px margin-top
```

### Responsive Behavior

| Breakpoint | Behavior |
|------------|----------|
| < 640px (mobile) | Card fills viewport width minus 16px horizontal padding. Industry grid becomes 2x5 (2 columns). Color swatches wrap to 2 rows if needed. |
| >= 640px (desktop) | Card at max-w-[600px] centered. Industry grid stays 2x4+1. Single row of color swatches. |

### Step Transitions

- Content area cross-fades between steps (150ms ease-in-out opacity transition).
- Step indicator updates immediately on navigation.
- No horizontal slide animation (keeps implementation simple, avoids layout shift).

## Interaction Contract

### Navigation Flow

| Action | Behavior |
|--------|----------|
| Click "Next" | Validate current step fields (blur + form-level). If valid, advance to next step. If invalid, show inline errors and focus first invalid field. |
| Click "Back" | Return to previous step. No validation triggered. Form data preserved. |
| Click step indicator dot | Jump to that step. No validation triggered for skipped steps. Form data preserved. |
| Click "Complete Setup" (Step 3) | Validate Step 3. Submit all data. Show loading spinner on button. On success: toast "Company setup complete" + redirect to `/dashboard`. On error: toast with error message. |
| Click "Skip for now" | Create minimal company record (user_id only, plus company name if entered). Redirect to `/dashboard`. No validation. |

### Logo Upload Interaction

| Action | Behavior |
|--------|----------|
| Click avatar circle | Open file picker (accept: `.png,.jpg,.jpeg`, max 2MB) |
| File selected (valid) | Show image preview in circle. Display "Change" and "Remove" links below. |
| File selected (too large) | Toast: "Logo must be under 2MB" |
| File selected (wrong format) | Toast: "Please upload a PNG or JPG image" |
| Click "Remove" | Clear preview, restore placeholder. |

### Industry Selector Interaction

| Action | Behavior |
|--------|----------|
| Click industry card | Select it (highlight border). Deselect previous selection. |
| Click "Other" card | Select it. Reveal text input below grid with placeholder "Enter your industry". Auto-focus the input. |
| Click different card after "Other" | Hide the custom input. Clear custom text. |

### Color Picker Interaction

| Action | Behavior |
|--------|----------|
| Click color swatch | Select it (ring highlight). Deselect previous. |
| Click "Custom" swatch | Open Popover with hex input field. Input has "#" prefix label. Validate 6-char hex on blur. |

### Form Validation

| Field | Rule | Error Message |
|-------|------|---------------|
| Company name (Step 1) | Required, min 2 chars | "Company name is required" / "Company name must be at least 2 characters" |
| Email (Step 1) | Optional, valid email format if provided | "Please enter a valid email address" |
| Website (Step 1) | Optional, valid URL format if provided | "Please enter a valid website URL" |
| Phone (Step 1) | Optional, no format enforcement | (none) |
| Tax rate (Step 3) | Optional, number 0-100 | "Tax rate must be between 0 and 100" |
| Custom industry (Step 2) | Required if "Other" selected, min 2 chars | "Please enter your industry" |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Step indicator | `aria-current="step"` on active step. `aria-label="Step N of 3: {title}"` on each dot. |
| Industry cards | `role="radiogroup"` on grid container. Each card is `role="radio"` with `aria-checked`. |
| Color swatches | `role="radiogroup"` on container. Each swatch is `role="radio"` with `aria-checked` and `aria-label="{color name}"`. |
| Logo upload | Hidden file input linked via `id`. Avatar circle has `role="button"` and `aria-label="Upload company logo"`. |
| Form errors | `aria-invalid="true"` and `aria-describedby` linking to error message element. |
| Skip link | Standard anchor/button. No special ARIA needed. |
| Focus management | On step change, focus moves to step title heading. |
