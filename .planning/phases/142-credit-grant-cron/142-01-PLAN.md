<objective>
THE load-bearing phase of v4.13 Annual Billing. Decouple the monthly AI-credit
grant from the Stripe invoice cadence so it is driven by the CALENDAR MONTH
instead — making exactly one `monthlyCreditGrant` per company per calendar month
for ANY billing interval.

Today the grant is a side-effect of `invoice.paid` keyed on `event.id`. That
works for monthly subs (one invoice/month → one grant/month) but BREAKS for
annual (one invoice/YEAR → one grant/year). Two coordinated changes converge on
one rule:

1. A SHARED `monthGrantKey(companyId, date)` helper → `grant:{companyId}:{YYYY-MM}`.
   The `invoice.paid` grant switches from `event.id` to this company-month key.
2. An Inngest monthly cron grants `monthlyCreditGrant` to every active paying
   company once per company-month using the SAME key, reusing the idempotent
   never-throw `grantCredits`.

WHY this works (the heart of the milestone):
- Monthly sub → `invoice.paid` grants each month (cron no-ops — key present).
- Annual sub → `invoice.paid` grants month 1; cron grants months 2-12.
- New signup → immediate first grant via the webhook (instant UX preserved).
Exactly one grant per company-month either way. The company-month key is the
SINGLE dedup authority shared by the webhook AND the cron.

Purpose: Let annual subscriptions exist without starving annual customers of 11
months of credits OR double-granting monthly ones. Get the company-month dedup
right and the rest of v4.13 (price field done in 141, checkout 143, seats 144,
UI 145) is mechanical.

Output: An exported `monthGrantKey` helper; the webhook grant re-keyed; a new
registered Inngest monthly cron; and the load-bearing no-double-grant regression
test proving a single ledger grant when the webhook and the cron run in the same
month.

SCOPE FENCE: the idempotency-key change + the shared key helper + the monthly
cron + its registration ONLY. NO annual price (141 done), NO checkout interval
(143), NO seat interval (144), NO UI (145). The cron does NOT care about interval
— it grants by TIER, monthly, for everyone. Do NOT add any interval logic here.
</objective>
