  return (

    >
      <ProgressPrimitive.Indicator

```
Note: `Progress` does NOT accept an `indicatorClassName` prop today — it hardcodes `bg-primary` on the Indicator. `UsageProgressBar` must NOT try to pass an unsupported prop through; instead render its OWN `ProgressPrimitive`-based markup OR wrap `<Progress>` and layer a colored overlay via a `style`/CSS-variable override. Simplest correct approach: copy the two-element structure directly inside `UsageProgressBar` (import `Progress as ProgressPrimitive` from `radix-ui` the same way `components/ui/progress.tsx` does, OR render `<Progress value={percentUsed} className="[&>[data-slot=progress-indicator]]:bg-[hsl(var(--success))]" />` using a Tailwind arbitrary-descendant selector keyed off `data-slot="progress-indicator"` — this works WITHOUT modifying `components/ui/progress.tsx` at all, since `className` on `Progress` targets the `Root`, and the arbitrary selector `[&>[data-slot=progress-indicator]]:bg-[...]` reaches the child `Indicator`).     ```typescript
    export function computeUsagePercent({ balance, cycleGrant }: { balance: number; cycleGrant: number }): number {
      if (cycleGrant <= 0) return 0
      const raw = Math.round((100 * (cycleGrant - balance)) / cycleGrant)
      return Math.max(0, Math.min(100, raw))
    }
    ```
    No `import 'server-only'` — this is a pure function importable from both server pages and (if ever needed) a client badge, matching the `lib/billing/calibration.ts` precedent of keeping pure math server/client-neutral.

      )
