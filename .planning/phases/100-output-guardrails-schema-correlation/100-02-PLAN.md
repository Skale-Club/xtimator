Create `lib/ai/price-anchoring.ts`:
- `export const UNIT_PRICE_CEILING = 1_000_000` (documented sane per-unit USD ceiling; no legitimate single line-item unit price exceeds $1M in this domain).
- `export function normalizeNameForMatch(name: string): string` with the EXACT body of `normalizeClientNameForMatch` (lowercase, trim, strip `[.,]`, collapse whitespace).
- `export interface AnchorResult { sections: EstimateSectionOutput[]; anchoredCount: number; clampedCount: number }`.
- `export function anchorAndClampSections(sections, priceBook: Array<{ name: string; unit_price: number }>): AnchorResult`:
  - Build `const bookByName = new Map(priceBook.map(p => [normalizeNameForMatch(p.name), p]))` (first-wins; wrap each `p.name`/`p.unit_price` read in a guard so a malformed row is skipped, never throws).
  - Map sections → items: `const hit = bookByName.get(normalizeNameForMatch(it.description))`. If hit and `Number.isFinite(hit.unit_price)`: `{ ...it, unit_price: hit.unit_price, price_source: 'price_book' }`, anchoredCount++. Else (ai_estimate, no anchor): if `it.unit_price > UNIT_PRICE_CEILING` → `{ ...it, unit_price: UNIT_PRICE_CEILING }`, clampedCount++; if `it.unit_price === 0` keep as-is; otherwise unchanged.
  - Return `{ sections: mappedSections, anchoredCount, clampedCount }`. Pure — no I/O, no companyId, no DB.

Create `lib/estimate/totals.ts`:
- `export const TOTALS_EPSILON = 0.01`.
- `export function round2(x: number): number` = `Math.round(x * 100) / 100`.
- `export function assertFinitePositive(x: number): number` = `Number.isFinite(x) && x >= 0 ? x : 0` (defensive zero-out; never throws).
- `export interface TotalsDiscrepancy { ai_grand: number; server_grand: number; delta: number; delta_pct: number | null; anchored_count: number; clamped_count: number; moved_by_guardrails: boolean }`.
- `export function computeTotalsDiscrepancy({ serverGrand, aiGrand, anchoredCount, clampedCount }): TotalsDiscrepancy`:
  - `const s = assertFinitePositive(serverGrand); const a = assertFinitePositive(aiGrand)`.
  - `delta = round2(s - a)`; `delta_pct = a > 0 ? round2((s - a) / a * 100) : null`; `moved_by_guardrails = anchoredCount > 0 || clampedCount > 0`.
  - Return the struct.
