    **Step 1 — Inventory all FAIL/issue entries from known-issues.md:**

    Run: `grep -B 1 -A 5 "FAIL" .planning/known-issues.md` and review

    For each FAIL or "Issues:" line with content, classify severity:
    - **BLOCKER**: feature totally broken, no workaround. Examples: Stripe webhook never fires; Inngest job never completes; signup crashes
    - **MAJOR**: feature degraded but workaround exists. Examples: trial banner shows wrong day count; admin force-tier requires page reload
    - **MINOR**: cosmetic or edge case. Examples: PT-BR translation missing on one button; logo upload accepts >5MB but should reject

    **Step 2 — Fix BLOCKERS in this milestone:**

    For each BLOCKER:
    1. Diagnose root cause
    2. Write fix
    3. Re-run the failing UAT test to confirm fix
    4. Commit with message `fix(69-03): <UAT-ID> — <one-line>`
    5. Update known-issues.md entry: change "FAIL" to "FIXED in <commit-sha>"

    **Step 3 — Document MAJOR/MINOR in known-issues.md:**

    For each non-blocker, ensure entry has:
    - Severity (MAJOR / MINOR)
    - Repro steps (1-3 lines)
    - Proposed fix direction
    - Target milestone (v3.2 / v3.3 / etc.)

    Example:
    ```markdown
    ### UAT-V30-03 — Trial Automation: PASS with caveat

      - Target: v3.2 (cosmetic)
    ```
