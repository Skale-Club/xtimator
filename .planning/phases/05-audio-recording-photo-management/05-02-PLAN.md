1. Create `components/workspace/audio/waveform-visualizer.tsx` ('use client'):
   - Props: `{ analyser: AnalyserNode | null; isRecording: boolean }`
   - Use `useRef` for canvas element and `requestAnimationFrame` loop
   - When `isRecording && analyser`: call `analyser.getByteTimeDomainData(dataArray)` in animation frame
   - Render vertical bars visualization: divide canvas into ~64 bars, map dataArray values (0-255, 128=silence) to bar heights
   - Bar color: `hsl(0, 84%, 60%)` (red) when recording, muted gray when idle
   - Canvas dimensions: `w-full h-24` with Tailwind, set canvas width/height from container via ResizeObserver or fixed 300x96
   - When not recording, render flat midline bars (128 values)
   - Cleanup: cancel animationFrame in useEffect cleanup

2. Create `components/workspace/audio/audio-recorder.tsx` ('use client'):
   - Props: `{ projectId: string; companyId: string; onRecordingCreated: (recording: Recording) => void }`
   - State: `isRecording`, `duration` (seconds), `audioBlob` (Blob | null), `isUploading`, `isTranscribing`, `liveTranscript`, `error`
   - Refs: `mediaRecorderRef`, `audioContextRef`, `analyserRef`, `streamRef`, `chunksRef`, `timerIntervalRef`, `speechRecognitionRef`

   **Start recording (per D-01, D-02, D-04, AUDIO-01, AUDIO-03, AUDIO-10):**
   - Request mic permission: `navigator.mediaDevices.getUserMedia({ audio: true })`. Catch `NotAllowedError` -> show "Microphone permission denied" error. Catch `NotFoundError` -> show "No microphone found".
   - Create `AudioContext` inside click handler (per Pitfall 2). Call `audioContext.resume()` if suspended.
   - Connect: `source = audioContext.createMediaStreamSource(stream)` -> `analyser = audioContext.createAnalyser()` (fftSize=256) -> `source.connect(analyser)`
   - Detect MIME: call `getSupportedAudioMimeType()`. Create `MediaRecorder(stream, mimeType ? { mimeType } : undefined)`
   - Set `ondataavailable` to push chunks. Set `onstop` to create Blob from chunks.
   - Start recorder, start timer interval (setInterval incrementing duration every 1000ms), set isRecording=true
   - Start Web Speech API if supported per D-03: check `window.SpeechRecognition || window.webkitSpeechRecognition`. If exists, create instance with `continuous=true`, `interimResults=true`, `lang='en-US'`. `onresult` concatenates all results into `liveTranscript`. `onerror` silently ignores. If not supported, show small "Live preview not available" text.

   **Stop recording (per D-05, AUDIO-05):**
   - Stop MediaRecorder. Stop timer interval. Stop SpeechRecognition if active.
   - Stop all stream tracks: `streamRef.current.getTracks().forEach(t => t.stop())`
   - Close AudioContext.
   - The `onstop` handler creates the Blob, stores in `audioBlob` state.

   **After stop UI (per D-05):**
   - Show Play button (creates `<audio>` element from Blob URL), Delete button (clears audioBlob, resets state), "Save & Transcribe" button.
   - On "Save & Transcribe": set isUploading=true, generate UUID for recordingId, compute storage path `{companyId}/{projectId}/{recordingId}.{ext}`, upload to Supabase Storage `audio` bucket via browser client, call `createRecording(projectId, storagePath, duration)`, then call `transcribeRecording(recordingId)`, set isTranscribing while waiting. On success call `onRecordingCreated(recording)`. On error show toast. Clean up Object URLs.

   **MM:SS timer (per D-02, AUDIO-02):**
   - Display `formatDuration(duration)` from `lib/utils/media-format.ts` above the waveform
   - Large text: `text-3xl font-mono`

   **Mic button (per D-02):**
   - Large circular button: `w-20 h-20 rounded-full` with Mic icon from lucide-react
   - When recording: `bg-red-500 animate-pulse` with MicOff icon
   - When idle: `bg-primary` with Mic icon
   - onClick toggles start/stop
