**File 1: `components/workspace/estimate/use-estimate-reducer.ts`** (per D-17)

Define the estimate editor state and reducer. This is the central state management for the entire editor.

State type:
```typescript
interface EditorSection {
  id: string; title: string; sort_order: number; subtotal: number;
  items: EditorItem[];
}
interface EditorItem {
  id: string; description: string; quantity: number; unit: string | null;
  unit_price: number; total: number; sort_order: number;
}
interface EstimateEditorState {
  id: string;
  summary: string | null; notes: string | null; timeline: string | null;
  payment_terms: string | null; warranty_terms: string | null;
  discount_type: string | null; discount_value: number; discount_amount: number;
  tax_rate: number; tax_amount: number;
  subtotal: number; total: number;
  sections: EditorSection[];
  isDirty: boolean;
}
```

Action types (discriminated union):
- `INIT` — Load full estimate from server data (EstimateWithSections). Sets isDirty=false.
- `UPDATE_FIELD` — Update top-level field (summary, notes, timeline, payment_terms, warranty_terms). Sets isDirty=true.
- `UPDATE_SECTION_TITLE` — { sectionId, title }. Sets isDirty=true.
- `UPDATE_ITEM` — { sectionId, itemId, field: 'description'|'quantity'|'unit'|'unit_price', value }. Recalculate item total, section subtotal, all totals. Sets isDirty=true.
- `ADD_ITEM` — { sectionId }. Add item with temp id (`'temp-' + crypto.randomUUID()`), quantity 1, unit_price 0, description '', sort_order = items.length. Sets isDirty=true.
- `REMOVE_ITEM` — { sectionId, itemId }. Remove item, recalculate. Sets isDirty=true.
- `ADD_SECTION` — Add section with temp id, title 'New Section', one empty item. Sets isDirty=true.
- `REMOVE_SECTION` — { sectionId }. Remove section, recalculate. Sets isDirty=true.
- `REORDER_ITEMS` — { sectionId, itemIds: string[] }. Update sort_order. Sets isDirty=true.
- `REORDER_SECTIONS` — { sectionIds: string[] }. Update sort_order. Sets isDirty=true.
- `UPDATE_DISCOUNT` — { discount_type, discount_value }. Recalculate discount_amount, tax, total. Sets isDirty=true.
- `UPDATE_TAX_RATE` — { tax_rate }. Recalculate tax_amount, total. Sets isDirty=true.
- `MARK_SAVED` — Sets isDirty=false.

**Recalculation helper** (used by multiple actions):
```typescript
function recalculate(state: EstimateEditorState): EstimateEditorState {
  const sections = state.sections.map(s => {
    const items = s.items.map(i => ({ ...i, total: Math.round(i.quantity * i.unit_price * 100) / 100 }))
    return { ...s, items, subtotal: items.reduce((sum, i) => sum + i.total, 0) }
  })
  const subtotal = sections.reduce((sum, s) => sum + s.subtotal, 0)
  let discount_amount = 0
  if (state.discount_type === 'percentage') discount_amount = Math.round(subtotal * state.discount_value / 100 * 100) / 100
  else if (state.discount_type === 'fixed') discount_amount = state.discount_value
  const tax_amount = Math.round((subtotal - discount_amount) * state.tax_rate * 100) / 100
  const total = Math.round((subtotal - discount_amount + tax_amount) * 100) / 100
  return { ...state, sections, subtotal, discount_amount, tax_amount, total }
}
```

Export `useEstimateReducer(initialEstimate: EstimateWithSections | null)` that calls `useReducer(reducer, initialEstimate, init)` where init converts EstimateWithSections to EditorState. Return `[state, dispatch]`.

**Generation flow (per D-12):**
When user clicks "Generate Estimate":
1. Set `isGenerating = true`, `generationStep = 0`.
2. If photos exist:
   - Set `generationStep = 0` ("Analyzing photos...")
   - `await fetch('/api/analyze-photos', { method: 'POST', body: JSON.stringify({ projectId }) })`
3. Set `generationStep = 1` ("Generating estimate...")
4. `await fetch('/api/generate-estimate', { method: 'POST', body: JSON.stringify({ projectId }) })`
5. Set `generationStep = 2` ("Saving...")
6. Brief pause (500ms) for UX.
7. Set `generationStep = 3` ("Done!")
8. After 1 second, call `router.refresh()` to reload server data, which will now include the estimate.
9. Set `isGenerating = false`.

On error at any step: show toast error via sonner, set isGenerating=false, show retry button.
