**Step 2: Build prompt (per D-05)**
System prompt (estimator persona):
```
You are a professional estimator for a {company.industry} business. Create a detailed, itemized estimate based on the job site information provided. Be thorough but realistic with pricing for the US market. Break the work into logical sections (e.g., Materials, Labor, Equipment). Each line item needs a clear description, quantity, unit (e.g., sq ft, hours, each, linear ft), and unit price.
```

User message content (concatenated):
1. "## Project Information\nName: {project.name}\nType: {project.project_type}\n{target_budget ? 'Target Budget: $' + target_budget : ''}\n{client info if available}"
2. "## Audio Transcripts\n" + recordings.filter(r => r.transcript).map(r => r.transcript).join('\n---\n')
3. "## Photo Descriptions\n" + photos.filter(p => p.ai_description).map((p, i) => `Photo ${i+1}: ${p.ai_description}`).join('\n')

**Step 4: Server-side math validation (per D-07)**
For each section, for each item: `item.total = Math.round(item.quantity * item.unit_price * 100) / 100`.
Section subtotal = sum of item totals.
Overall subtotal = sum of section subtotals.
Tax rate from company defaults: `tax_rate = company.default_tax_rate || 0`.
Tax amount = `Math.round(subtotal * tax_rate * 100) / 100`.
Grand total = `subtotal + tax_amount` (no discount on initial generation).

**Step 5: Version management (per D-09)**
```typescript
// Mark all existing estimates as not current
await supabase.from('estimates').update({ is_current: false }).eq('project_id', projectId)

// Get next version number
const { data: existingEstimates } = await supabase.from('estimates').select('version').eq('project_id', projectId).order('version', { ascending: false }).limit(1)
const nextVersion = (existingEstimates?.[0]?.version ?? 0) + 1
```

**Step 6: Persist to DB (per D-08)**
Insert estimate row with: project_id, company_id, version: nextVersion, is_current: true, status: 'draft', summary, notes, timeline, payment_terms (AI value or company.default_payment_terms), warranty_terms (AI value or company.default_warranty_terms), subtotal, tax_rate, tax_amount, total. Get back the estimate id.

For each section (with sort_order = index): insert into estimate_sections with estimate_id, company_id, title, sort_order, subtotal. Get back section id.

For each item in section (with sort_order = index): insert into estimate_items with section_id, company_id, description, quantity, unit, unit_price, total (server-calculated), sort_order.

**Action 1: `saveEstimate`** (used by editor auto-save, per D-22)
```typescript
export async function saveEstimate(estimateData: {
  id: string
  summary: string | null
  notes: string | null
  timeline: string | null
  payment_terms: string | null
  warranty_terms: string | null
  discount_type: string | null
  discount_value: number
  tax_rate: number
  sections: {
    id: string  // existing section id, or temp id starting with 'temp-'
    title: string
    sort_order: number
    items: {
      id: string  // existing item id, or temp id starting with 'temp-'
      description: string
      quantity: number
      unit: string | null
      unit_price: number
      sort_order: number
    }[]
  }[]
})
```

Logic:
1. Auth check via getAuthContext().
2. **Recalculate all math server-side** (never trust client math):
   - For each item: `total = Math.round(quantity * unit_price * 100) / 100`
   - For each section: `subtotal = sum of item totals`
   - `subtotal = sum of section subtotals`
   - If discount_type === 'percentage': `discount_amount = Math.round(subtotal * discount_value / 100 * 100) / 100`
   - If discount_type === 'fixed': `discount_amount = discount_value`
   - Else: `discount_amount = 0`
   - `tax_amount = Math.round((subtotal - discount_amount) * tax_rate * 100) / 100`
   - `total = subtotal - discount_amount + tax_amount`
3. Update estimate row: summary, notes, timeline, payment_terms, warranty_terms, discount_type, discount_value, discount_amount, tax_rate, tax_amount, subtotal, total, updated_at.
4. For each section:
   - If id starts with 'temp-': INSERT new section row (generate real id), get back id.
   - Else: UPDATE existing section row (title, sort_order, subtotal).
5. For each item in each section:
   - If id starts with 'temp-': INSERT new item row.
   - Else: UPDATE existing item row (description, quantity, unit, unit_price, total, sort_order).
6. Delete any sections/items that exist in DB but are NOT in the incoming data:
   - Fetch current section ids: `supabase.from('estimate_sections').select('id').eq('estimate_id', estimateData.id)`
   - Delete sections whose id is not in the incoming sections list.
   - Items cascade-delete with their section, but also delete orphaned items within kept sections.
7. Update `projects.total` to match new grand total.
8. `revalidatePath('/projects/...')`
9. Return `{ data: { total } }` on success.
