<task type="auto">
  <name>Task 2: Implement POST /api/analyze-photos route</name>
  <files>app/api/analyze-photos/route.ts</files>
  <action>
Create `app/api/analyze-photos/route.ts` as a Next.js Route Handler (per D-01).

**Auth pattern for route handlers** (different from server actions): Use `createClient()` from `@/lib/supabase/server`, then `supabase.auth.getClaims()` to verify auth. Query companies table to get company_id. Return 401 on auth failure.

**Route logic (per D-01, D-02, D-03):**

1. Parse JSON body: `{ projectId: string }`. Return 400 if missing.
2. Auth check: get user via getClaims, get company_id. Return 401 if unauthenticated.
3. Fetch photos: `supabase.from('photos').select('*').eq('project_id', projectId).order('sort_order')`. Return 400 if no photos.
4. For each photo, use `Promise.allSettled()` (per D-02) to run in parallel:
   a. Download photo from Supabase Storage using service role client: `createServiceClient().storage.from('photos').download(photo.storage_path)`.
   b. Convert the Blob to a base64 string.
   c. Call Claude Vision API using the Anthropic SDK (per D-03):
      ```typescript
      import Anthropic from '@anthropic-ai/sdk'
      const anthropic = new Anthropic() // reads ANTHROPIC_API_KEY from env
      const response = await anthropic.messages.create({
        model: 'claude-sonnet-4-20250514',
        max_tokens: 200,
        messages: [{
          role: 'user',
          content: [
            { type: 'image', source: { type: 'base64', media_type: mimeType, data: base64Data } },
            { type: 'text', text: 'Describe this photo from a contractor\'s perspective. Note materials, conditions, measurements if visible, damage, and areas needing work. Be specific and concise.' }
          ]
        }]
      })
      ```
   d. Extract text from response: `response.content[0].type === 'text' ? response.content[0].text : ''`
   e. Update photo row: `supabase.from('photos').update({ ai_description: description }).eq('id', photo.id)` (use the authenticated supabase client, not service role, since RLS allows owner updates).

5. Collect results from Promise.allSettled. Build a response array:
   ```typescript
   { results: photos.map((photo, i) => ({
     photoId: photo.id,
     status: results[i].status, // 'fulfilled' or 'rejected'
     description: results[i].status === 'fulfilled' ? results[i].value : null,
     error: results[i].status === 'rejected' ? results[i].reason?.message : null
   })) }
   ```
6. Return `NextResponse.json(response, { status: 200 })`.

**Important:** Determine mime type from storage_path extension: `.jpg`/`.jpeg` -> `image/jpeg`, `.png` -> `image/png`, `.webp` -> `image/webp`. Default to `image/jpeg`.

**Error handling:** Wrap the entire handler in try/catch, return 500 on unexpected errors.
