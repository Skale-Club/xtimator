# Phase 143 Plan 01: Annual Checkout

## Goal

`create-checkout-session` accepts `billingInterval: 'month' | 'year'` (default `'month'`), routes to annual Stripe Price IDs for `'year'`, stores `billing_interval` in metadata. Monthly path byte-identical to today.

## Success Criteria

1. `billingInterval: 'year'` selects `STRIPE_PRICE_PRO_ANNUAL` / `STRIPE_PRICE_BUSINESS_ANNUAL` env vars; returns 500 with clear error if unset (mirrors monthly guard)
2. Checkout Session + `subscription_data.metadata` carries `billing_interval` alongside existing `companyId` + `plan`
3. No `billingInterval` or `billingInterval: 'month'` → byte-identical to today (same Price ID, same metadata shape + `billing_interval: 'month'`)
4. `.env.local.example` and `.env.production.example` document `STRIPE_PRICE_PRO_ANNUAL` / `STRIPE_PRICE_BUSINESS_ANNUAL` with PLACEHOLDER values only — no real IDs

## Tasks

### Task 1: Extend checkout route

**File**: `app/api/billing/create-checkout-session/route.ts`

**Changes**:
- Parse `billingInterval` from request body: `const billingInterval = body.billingInterval === 'year' ? 'year' : 'month'`
- Select Price ID based on interval:
  ```ts
  const priceId =
    billingInterval === 'year'
      ? plan === 'pro'
        ? process.env.STRIPE_PRICE_PRO_ANNUAL
        : process.env.STRIPE_PRICE_BUSINESS_ANNUAL
      : plan === 'pro'
        ? process.env.STRIPE_PRICE_PRO
        : process.env.STRIPE_PRICE_BUSINESS
  ```
- Guard: if annual interval + no annual priceId → `{ error: 'STRIPE_PRICE_{PLAN}_ANNUAL env var not set' }` 500
- Add `billing_interval: billingInterval` to both `metadata` and `subscription_data.metadata`

**Retrocompat**: when `billingInterval` is absent/`'month'`, the existing `priceId` selection + existing metadata fields are identical; the only addition is `billing_interval: 'month'` appended to both metadata objects.

### Task 2: Document env vars with placeholders

**Files**: `.env.local.example`, `.env.production.example`

Under the existing Stripe block, add:
```
# STRIPE_PRICE_PRO_ANNUAL=price_<your-annual-pro-price-id>
# STRIPE_PRICE_BUSINESS_ANNUAL=price_<your-annual-business-price-id>
```

**CRITICAL**: placeholder values only. NEVER a real `price_*` ID. These are commented-out examples.

### Task 3: Unit tests

**File**: `tests/unit/billing/annual-checkout.test.ts` (new)

Test cases (mock the Stripe client's `checkout.sessions.create`):
1. `billingInterval: 'year'` + pro → uses `STRIPE_PRICE_PRO_ANNUAL`, metadata has `billing_interval: 'year'`
2. `billingInterval: 'year'` + business → uses `STRIPE_PRICE_BUSINESS_ANNUAL`
3. `billingInterval: 'year'` + annual env unset → 500 with clear error message
4. `billingInterval: 'month'` → uses `STRIPE_PRICE_PRO`, metadata has `billing_interval: 'month'`
5. No `billingInterval` (omitted) → same as `'month'` path
6. `billing_interval` present in `subscription_data.metadata` for all cases

**Mock pattern**: follow existing `tests/unit/webhooks/stripe-credit-grant.test.ts` — vi.mock the stripe client and supabase server, assert on the captured `create()` call payload.
