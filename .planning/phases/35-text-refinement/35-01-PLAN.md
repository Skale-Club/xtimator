  <action>
Create new API route at /api/estimates/[id]/refine:

1. POST endpoint, requires authentication
2. Validates estimate ID exists and belongs to user's company
3. Fetches current estimate with sections and items (use getEstimateById)
4. Loads company price book (use getPriceBookItems)
5. Gets user instruction from request body: { instruction: string }
6. Calls AI provider with refinement prompt (see below)
7. Creates new version (set is_current=false on old, insert new with version+1)
8. Persists refined estimate to DB
9. Returns { success: true, newVersion: number, estimateId: string }

```
Existing estimate (current state):
{JSON of estimate with sections and items}

{price book items as JSON}

"{user instruction text}"

Task: Update the estimate to reflect the user's instruction.
- Modify, add, or remove items/sections as needed
- Keep everything else unchanged
- Preserve price_source tagging
- Return the full updated estimate in the same JSON format
```
