<objective>
Build the `OgImageUploader` client component and wire it into the SEO editor form, replacing the bare URL input. This plan covers UI + client-side validation only. Server-side upload action and remove confirmation modal land in Plan 78-02.

Purpose: Owners currently must self-host an OG image and paste a URL — error-prone and breaks when the host disappears. This phase makes the OG image a first-class managed asset.
Output: A functional dropzone with preview + dimension validation rendered on `/admin/seo`. Selecting a file holds it in component state ready for Plan 02 to upload; existing external URLs still render via the preview fallback path.

Addresses requirements: OG-IMG-01 (dropzone + format/size validation), OG-IMG-02 (1200x630 preview + dimension warning), OG-IMG-05 (backward-compat for external URLs).
</objective>
