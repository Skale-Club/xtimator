    **1. Extend `seoSchema` in `lib/schemas/admin.ts`:**

    Add two optional fields. Use `z.instanceof(File)` for the file (same pattern used by `brandingSchema.logoFile`):
    ```typescript
    ogImageFile: z.instanceof(File)
      .refine(f => f.size <= 2 * 1024 * 1024, 'OG image must be under 2MB.')
      .refine(f => ['image/png', 'image/jpeg', 'image/jpg'].includes(f.type), 'OG image must be a PNG or JPG.')
      .nullable()
      .optional(),
    ogImageRemoved: z.boolean().optional().default(false),
    ```
    Keep existing `ogImageUrl` field unchanged — it remains the source of truth for the persisted URL when no file uploaded and no removal requested.

    **2. Extend `saveSeo` in `app/admin/seo/actions.ts`:**

    Mirror the logo upload block from `app/admin/branding/actions.ts` lines 24-61. Add to the `raw` parse object:
    ```typescript
    const rawOgFile = formData.get('ogImageFile')
    const ogImageFile = rawOgFile instanceof File && rawOgFile.size > 0 ? rawOgFile : null
    const ogImageRemoved = formData.get('ogImageRemoved') === 'true'
    ```
    Pass `ogImageFile` and `ogImageRemoved` through `seoSchema.safeParse` so the size/type refinements run server-side. On parse failure return `{ok:false, message: parsed.error.issues[0]?.message ?? 'Validation failed'}` (matches existing pattern).

    **3. Upload branch** (when `parsed.data.ogImageFile` is non-null):
    - Determine ext: `const ext = (file.name.split('.').pop() || 'png').toLowerCase()`.
    - Sanitize base name: `const base = file.name.replace(/\.[^.]+$/, '').toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '') || 'og-image'`.
    - Key: `const path = \`og-images/${Date.now()}-${base}.${ext}\``.
    - `const storage = createStorage(svc)` (reuse the `svc = requireServiceClient()` already in the function).
    - `await storage.upload('platform-brand', path, Buffer.from(await file.arrayBuffer()), {contentType: file.type, upsert: true})`.
    - On throw return `{ok:false, message: err.message ?? 'Upload failed.'}`.
    - `const newOgUrl = storage.getPublicUrl('platform-brand', uploadedPath)` → use this as the value written to `og_image_url` (overrides `parsed.data.ogImageUrl`).

    **4. Remove branch** (when `parsed.data.ogImageRemoved === true` AND no new file uploaded):
    - Read the **current** `og_image_url` from DB BEFORE the upsert (single SELECT on `platform_branding` by `id=1`).
    - If it matches the managed prefix (string contains `/platform-brand/og-images/`), extract the storage path (everything after `/platform-brand/`) and call `storage.delete('platform-brand', extractedPath)` inside a try/catch. Swallow errors — log via `console.warn` for observability but do not return an error.
    - Set the value to write to `og_image_url` = `null`.

    **5. Upsert payload:**
    Replace the existing `og_image_url: parsed.data.ogImageUrl` with the computed value:
    ```typescript
    let finalOgUrl: string | null = parsed.data.ogImageUrl
    if (newOgUrl) finalOgUrl = newOgUrl
    else if (parsed.data.ogImageRemoved) finalOgUrl = null
    ```
    Persist `og_image_url: finalOgUrl`.

    **6. Audit log:** Extend `metadata` with `og_image_uploaded: !!newOgUrl, og_image_removed: parsed.data.ogImageRemoved`.

    **7. Tests:** Create `tests/unit/admin/save-seo.test.ts`. Mock `requireAdmin`, `requireServiceClient` (chainable upsert / select stub), `createStorage` (factory returning mocked `upload/getPublicUrl/delete`), `logAdminAction`, `invalidatePlatformConfig`, `revalidatePath`. Build FormData with `new FormData()` + `formData.append('ogImageFile', new File([new Uint8Array(size)], name, {type}))`. Cover the 7 behaviors above.
