Preview deposit math (mirror compute-totals.ts L177-190 EXACTLY):
```
deposit = deposit_type === 'percent' ? round2(total * (deposit_value ?? 0)/100)
        : deposit_type === 'amount'  ? round2(deposit_value ?? 0)
        : 0
balance_due = round2(total - deposit)
```
where round2(x) = Math.round(x * 100) / 100.

DEPOSIT TYPE DOMAIN (LOCKED): the deposit uses `'none' | 'percent' | 'amount'` (matches the DB CHECK + the engine). This differs from the DISCOUNT type which uses `'percentage' | 'fixed'` — do NOT conflate them. saveEstimate (Plan 01) passes deposit_type straight to the engine (no mapping needed for deposit).
