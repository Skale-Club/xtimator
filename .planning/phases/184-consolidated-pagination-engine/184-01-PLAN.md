- `linebreak`'s `LineBreaker` gives break opportunities immediately after each space (chunk includes the trailing space)

Reference greedy line-packer (the exact algorithm to hand-validate in Task 1):
```ts
function estimateLineCount(text: string, font: Font, fontSizePt: number, maxWidthPt: number): number {
  if (text.length === 0) return 0
  const scale = fontSizePt / font.unitsPerEm
  const breaker = new LineBreaker(text)
  let lineWidthPt = 0
  let lines = 1
  let last = 0
  let bk: { position: number } | null
  while ((bk = breaker.nextBreak())) {
    const chunk = text.slice(last, bk.position)
    const { advanceWidth } = font.layout(chunk)
    const chunkWidthPt = advanceWidth * scale
    if (lineWidthPt + chunkWidthPt > maxWidthPt && lineWidthPt > 0) {
      lines += 1
      lineWidthPt = chunkWidthPt
    } else {
      lineWidthPt += chunkWidthPt
    }
    last = bk.position
  }
  return lines
}
```

**Line-height metrics** (Task 3's target — confirmed via `node -e` against all 4 vendored TTFs, replicating `@react-pdf/pdfkit`'s OWN internal formula read directly from source: `node_modules/@react-pdf/pdfkit/lib/pdfkit.js:37651-37657` — `lineHeight(size, includeGap) { const gap = includeGap ? this.lineGap : 0; return (this.ascender + gap - this.descender) / 1000 * size }`, where `ascender`/`descender`/`lineGap` are each pre-scaled by `1000 / unitsPerEm` at font-embed time (`pdfkit.js:37413-37417`) — algebraically this collapses to a single unitless multiplier independent of the 1000-scale step):

```
LINE_HEIGHT_MULTIPLIER = (ascent - descent + lineGap) / unitsPerEm
```

| Font file | ascent | descent | lineGap | unitsPerEm | multiplier |
|---|---|---|---|---|---|
| `public/fonts/inter/Inter-Regular.ttf` | 1984 | -494 | 0 | 2048 | **1.21** (`2478/2048 = 1.20996`) |
| `public/fonts/inter/Inter-Bold.ttf` | 1984 | -494 | 0 | 2048 | **1.21** (identical metrics to Regular) |
| `public/fonts/lora/Lora-Regular.ttf` | 1006 | -274 | 0 | 1000 | **1.28** (`1280/1000 = 1.28`) |
| `public/fonts/lora/Lora-Bold.ttf` | 1006 | -274 | 0 | 1000 | **1.28** (identical metrics to Regular) |

These are the EXACT `LINE_HEIGHT` values to commit (do not re-derive differently) — `LINE_HEIGHT = { Inter: 1.21, 'Inter-Bold': 1.21, Lora: 1.28, 'Lora-Bold': 1.28 }`.
