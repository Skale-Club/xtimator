```ts
export function isPublicRoute(pathname: string) {

  return pathname === '/' || isAuthRoute || isPublicEstimate
```

Replace with:
```ts
export function isPublicRoute(pathname: string) {
  const isAuthRoute =
    pathname.startsWith('/login') ||
    pathname.startsWith('/signup') ||
    pathname.startsWith('/reset-password') ||
    pathname === '/callback'
  const isPublicEstimate = pathname.startsWith('/estimate')

  return pathname === '/' || isAuthRoute || isPublicEstimate
}
```

Rationale: `app/(auth)/` is a parenthetical route group — the parens are stripped from the URL. The actual URLs are `/login`, `/signup`, `/reset-password`, `/callback`. The old `pathname.startsWith('/auth')` was NEVER true for these routes, so every unauthenticated visit to these pages was redirected (infinite redirect loop or 404 depending on path).

**Change 2 — redirect target in updateSession (line 42):**

Current code:

