# Phase 145 Plan 01: Pricing UI Toggle

## Goal

Tier cards gain a Monthly/Annual toggle. Annual view shows: annual price, per-month equivalent (`annual ÷ 12`), and a "Save X%" badge derived at render time (`Math.round((1 − annual/(12×monthly)) × 100)`). Selected interval threads into the checkout call. Graceful degradation when annual price is unconfigured. All strings through `t()`.

## Success Criteria

1. Toggle renders; Annual mode shows annual price, per-month-equivalent, and derived save-X% badge — no hardcoded % or price
2. Annual CTA → `billingInterval: 'year'` in checkout; Monthly CTA → `billingInterval: 'month'` (byte-identical to today)
3. Tier with `subscriptionPriceAnnualCents` null/0 → Annual toggle hides that tier's annual option or shows clear unavailable state
4. All new strings (toggle labels, "Save X%", "per month", period labels) through `t()` — static test asserts no bare English in new JSX
5. Mobile-safe (usable iOS Safari + Android Chrome)

## Architecture Decision

The billing_config is server-side only. The component `TierCardsGrid` is a client component. We need to pass the annual prices as props from a server component (the settings/billing page) into the client grid component.

**Approach**:
- Server component (`app/(app)/settings/billing/page.tsx` or wherever tier cards are rendered) calls `getBillingConfig()` and passes `annualPrices: { pro?: number, business?: number }` to `TierCardsGrid`
- `TierCardsGrid` receives `annualPrices` prop and uses it for the toggle; TIERS array stays as-is for monthly prices
- No hardcoded prices in the component

### Task 2: Add annualPrices prop to TierCardsGrid

**File**: `components/billing/tier-cards-grid.tsx`

1. Add props:
   ```ts
   interface TierCardsGridProps {
     currentTier: Tier | 'trial'
     annualPrices?: { pro?: number | null; business?: number | null }
   }
   ```
2. Add `billingInterval` state: `const [interval, setInterval] = useState<'month' | 'year'>('month')`
3. Add Monthly/Annual toggle above the cards grid:
   ```tsx
   <div className="flex items-center justify-center gap-2 mb-6">
     <button onClick={() => setInterval('month')} ... >{t('Monthly')}</button>
     <button onClick={() => setInterval('year')} ... >{t('Annual')}</button>
   </div>
   ```
4. Thread `interval` into `handleSelect`:
   ```ts
   body: JSON.stringify({ plan: tier, billingInterval: interval }),
   ```
5. For each paid tier in Annual mode:
   - Get `annualPrice` from `annualPrices?.[tier]`
   - If `annualPrice` falsy → hide annual CTA or show "Not available" 
   - If `annualPrice` set:
     - `displayPrice = '$' + (annualPrice / 100).toFixed(0)`  (annual total)
     - `perMonth = '$' + (annualPrice / 100 / 12).toFixed(2)` + `t('/mo')`
     - `savePct = Math.round((1 - annualPrice / (monthlyPriceCents * 12)) * 100)` — needs the monthly price in cents; parse it from the TIERS array OR pass monthly prices as cents too

**Note on monthly price in cents**: The TIERS array has `price: '$29'` as strings — not cents. To derive the discount badge we need cents. Options:
- Add `priceCents: number` to each tier in the TIERS constant (29_00, 99_00) — these are display constants, not billing numbers. They must match what's in billing_config but we can note that in a comment.
- OR pass `monthlyPrices` from the server too: `{ pro: number, business: number }` from `getBillingConfig().tiers.pro.subscriptionPriceCents`

**Recommended**: pass both `annualPrices` and `monthlyPricesCents` from the server component (read from `getBillingConfig()`). This makes the component fully config-driven and the save-badge correctly derived even if the operator adjusts the monthly price.
