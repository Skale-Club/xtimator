Wire quota enforcement into the two web API routes that consume paid AI capacity.

Purpose: Before any Anthropic/Claude Vision call starts, verify the company has remaining quota. After a successful AI call, record the usage event with an idempotency key. A quota-exceeded request never reaches the AI — it returns HTTP 402 immediately.

Output: Two modified route files + two new test files proving the enforcement contract.
</objective>

- Uses `createClient()` (authenticated Supabase client)
- Auth: getClaims() → userId → companyRow (id) → companyId
- Rate limit checks happen BEFORE companyId is resolved
- `generateEstimateForProject(companyId, projectId)` is the AI call
- Returns `NextResponse.json(result)` on success

From app/api/analyze-photos/route.ts (current structure):
- Uses both `createClient()` (auth) and `requireServiceClient()` (storage downloads)
- Auth: getClaims() → userId → company (id) → companyId
- Photos fetched: `supabase.from('photos').select('*').eq('project_id', projectId)`
- AI: `Promise.allSettled(typedPhotos.map(photo => analyzePhoto(...)))` is the AI call
- `photos.length` is the photo count for recordUsage units
