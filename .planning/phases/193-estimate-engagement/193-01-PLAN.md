# 193-01 — Engagement schema + tracking pipeline

**Goal:** every visit to a shared estimate produces durable, queryable engagement events
(opens, clicks with coordinates, scroll depth, section visibility, time-on-page) without
weakening the share page's security posture or overloading the anonymous surface.

## Task 1 — Migration `supabase/migrations/<ts>_phase193_estimate_engagement.sql`

New table (follow `tour_events` precedent — session-level, no project scoping):

```sql
CREATE TABLE estimate_engagement_events (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  estimate_id uuid NOT NULL REFERENCES estimates(id) ON DELETE CASCADE,
  company_id uuid NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  visitor_id text NOT NULL,          -- anonymous localStorage uuid, NOT auth users
  session_id text NOT NULL,          -- per-tab uuid
  event_type text NOT NULL CHECK (event_type IN
    ('view','click','scroll_depth','section_view','heartbeat','unlock_ok','unlock_fail')),
  target text,                       -- section/element id for click + section_view
  x_pct numeric(5,2),                -- click x as % of document width (0-100)
  y_px integer,                      -- click y in px from document top
  doc_h integer,                     -- document height at event time (for scaling)
  viewport_w integer,
  device text CHECK (device IN ('mobile','desktop')),
  metadata jsonb NOT NULL DEFAULT '{}'::jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

- Indexes: `(estimate_id, created_at)`, `(company_id, created_at)`.
- RLS **enabled**; single policy: SELECT for `authenticated` scoped by membership on
  `company_id` (copy the pattern used by `estimate_activity` policies in
  `20260706000007_rls_hardening_indexes_grants.sql`). **No anon policies, no INSERT
  policy** — all writes go through the service-role client.
- Estimates columns: `ALTER TABLE estimates ADD COLUMN view_count integer NOT NULL DEFAULT 0,
  ADD COLUMN last_viewed_at timestamptz;` (`viewed_at` keeps meaning *first* view).
- No IP / user-agent columns — deliberate (privacy decision in CONTEXT).

regenerate `types/database.types.ts`; expect the two CRLF migration-shape tests to fail

## Task 3 — `app/api/track/estimate/route.ts` (public batch collector)

Model on `app/api/csp-report/route.ts`:

- `POST` only, `export const dynamic = 'force-dynamic'`, always returns `204`, never throws.
- Body (zod): `{ token: string, events: Event[] }` — `token` is the **share_token or
  public_slug_token**; cap `events.length` at 25 and total body at ~32KB; clamp numeric
  fields; whitelist `event_type` (reject `unlock_*` here — those are server-emitted only).
- Order of operations (mirrors the sign route's rule — throttle before anything runs):
  1. `rateLimit('trackEstimatePerMinute', ip)` → silent 204 drop when exceeded.
  2. Resolve estimate via service client by exact token match (both token kinds), check
     `isShareLinkExpired`; unknown/expired → 204 drop (no oracle).
  3. Demo guard: `assertCompanyWritable(companyId)`-equivalent check; demo → 204 drop.
  4. Bulk insert rows; on `view` events also
     `UPDATE estimates SET view_count = view_count + <n>, last_viewed_at = now()`.
- Register in `MUTATION_BOUNDARY_MANIFEST` (`tests/unit/demo/mutation-boundary-sweep.test.ts`
  line ~404) as `guarded(...)` — follow the `app/estimate/[token]/actions.ts` entry at ~612.

## Task 4 — Client tracker `hooks/use-estimate-tracking.ts` + wiring

`'use client'` hook consumed by `components/share/estimate-view.tsx` (it already receives
the real `token` on both routes):

- Identity: `visitor_id` in `localStorage` (uuid, created lazily, try/catch — Safari
  private mode), `session_id` per mount via `crypto.randomUUID()`.
- Emit `view` once per mount. Device = `viewport_w < 768 ? 'mobile' : 'desktop'`.
- Clicks: one capture-phase listener on the document container; record
  `x_pct` (relative to container width), `y_px` (offsetTop within container), `doc_h`,
  and `target` = nearest `[data-track-section]` ancestor id.
- Sections: add `data-track-section` attributes to the major blocks of both renderers
  (`components/share/estimate-document-modern.tsx`,
  `components/workspace/estimate/estimate-document.tsx`): header, line-items, totals,
  timeline, terms, signature, photos. `IntersectionObserver` (50% threshold, once per
  section per session) → `section_view`.
- Scroll depth milestones 25/50/75/100 (once each per session) → `scroll_depth`
  with `metadata.pct`.
- `heartbeat` every 20s **only while `document.visibilityState === 'visible'`**,
  `metadata.seconds: 20`, hard cap 30 heartbeats/session (10 min).
- Transport: buffer events, flush every 5s and on `visibilitychange→hidden` /
  `pagehide` via `navigator.sendBeacon` (fallback `fetch keepalive`). All failures silent.
- Do **not** track when the page renders the locked/password state (193-02).
