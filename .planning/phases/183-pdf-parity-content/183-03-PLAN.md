<!-- Dockerfile's runner stage (verified this session) — WHY these files MUST live under public/, not assets/ -->
```dockerfile
# builder stage: COPY . .  (everything, including public/)
# runner stage:
COPY --from=builder --chown=nextjs:nodejs /app/public ./public
COPY --from=builder --chown=nextjs:nodejs /app/.next/standalone ./
COPY --from=builder --chown=nextjs:nodejs /app/.next/static ./.next/static
```
Only `public/`, `.next/standalone`, and `.next/static` are copied into the final runtime image (`next.config.ts:67` has `output: 'standalone'`). A folder OUTSIDE `public/` (e.g. `assets/fonts/`) would build fine locally/in the builder stage but be SILENTLY MISSING in the deployed container, breaking Font.register only in production. This is why font files go under `public/fonts/`, not `assets/fonts/`.
