<objective>
Wrap all ~80 high-frequency user-visible strings in the authenticated app with t() from useTranslation.

Purpose: This plan completes I18N-03 — the string wrapping pass that makes the UI translatable. Without this pass, the components exist but no text is routed through the translation system. This is the final plan of the phase.

Output: Every targeted 'use client' component in the authenticated app uses const { t } = useTranslation() and all UI strings from D-08 are wrapped in t().

Scope: ONLY 'use client' components in the authenticated app. Server components render EN directly (per D-09). Admin panel, landing page, and estimate share page are explicitly out of scope (per CONTEXT.md deferred items).
</objective>

<!-- useTranslation usage pattern — add to every 'use client' component -->
```typescript
// 1. Add import at top of file
import { useTranslation } from '@/lib/i18n/use-translation'

// 2. Add at top of component function body
const { t } = useTranslation()

// 3. Wrap static strings
<Button>{t('Save')}</Button>
<h2>{t('Dashboard')}</h2>
<EmptyState title={t('No clients yet')} description={t('Add your first client to get started')} />
```

```typescript
// NAV_ITEMS is typed as NavItem[], consumed in BottomNav and Sidebar

// Option B: make label a function — AVOID this (breaks NavItem type)

// IMPORTANT: Do NOT modify nav-items.ts — it is a data file, not a component.
//            NAV_ITEMS labels are plain strings; t() belongs at the render site.
```

```

They render EN text directly. Examples: page.tsx files without 'use client'.
Only add t() to files that already have 'use client' or to components
that are already client components.
```
