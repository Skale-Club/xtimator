<objective>
Add a seat-cost transparency line to the existing Settings → Team surface (SEAT-08, the FINAL phase of v4.12). The owner/admin sees, in one clear summary, the org's current active seat count, the configured per-seat price, and the projected monthly seat cost — all derived at runtime from `billing_config` (via `getBillingConfig()`) reusing the SAME pure `computeBillableSeats`/`computeSeatChargeCents` math the Phase-139 billing sync uses, so the disclosed number can never diverge from what would be charged. Mirrors the SEED-036 1%-fee transparency principle.

Purpose: Billing transparency — the owner sees exactly what seats cost, sourced from the one configurable place, never hardcoded copy.
Output: A pure server-side summary builder (`lib/billing/seat-cost-summary.ts`), the team page server component computing + passing the summary, and the TeamSection rendering it (owner/admin only, mobile-safe, i18n en/pt/es, truthful when enforcement is off).
</objective>
