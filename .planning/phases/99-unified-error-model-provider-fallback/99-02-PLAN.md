<objective>
Implement HARD-04: one typed failure/error model across routes, graph nodes, Inngest functions and adapters. Promotes the graph's free-string `failure.reason` to a typed `FailureReason` union, adds one mapping module (`lib/estimate/failure.ts`) deriving both an `XtimatorError` (HTTP boundary) and channel copy (adapters) from that single union, and removes the refine route's ad-hoc `throw -> 500` in favor of `asResponse(err)`.

Purpose: Every layer speaks one failure language with one mapping to a channel response; no opaque 500s on the estimate paths.
Output: `lib/estimate/failure.ts`, typed `state.ts` failure channel, typed producers/readers in generate.ts + both adapters, and a wrapped refine route. Makes the Wave-0 HARD-04 tests GREEN. Behavior-preserving except removing the refine bare-throw->500.
</objective>
