<objective>
Add a one-line `isDemoCompany(...)` redirect guard to every settings page NOT in the demo-exposed set (Company/Team/Notifications), so a demo visitor who bookmarks or guesses a hidden tab's URL is bounced to `/settings/company` instead of rendering real billing/integration/knowledge/account content.

Purpose: Plan 01's `SettingsNav` filter only hides the nav link — without this plan, a demo visitor could still reach hidden tabs by direct URL, violating PARITY-02's "settings surfaces intentionally exposed to the demo" boundary (Pitfall 2 in 181-RESEARCH.md: nav-hidden-but-URL-still-renders is a confusing UX regression).
Output: 15 settings pages each redirect a demo session to `/settings/company`, matching each file's own pre-existing `redirect(...)` idiom; zero behavior change for real tenants.
</objective>
