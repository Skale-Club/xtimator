<objective>
Ship the team-invite transactional email (`sendInviteEmail`) as a self-contained
Resend template that mirrors the existing `lib/email/account-emails.ts` contract.
This is the email layer of SEAT-03 — Plan 02's `inviteMember` action calls it.

Building it first (Wave 1) gives Plan 02 a defined function signature to call
with no codebase exploration. The function takes a pre-generated token + accept
URL inputs and produces/sends the email; it does NOT generate the token or touch
the database (that is the action's job in Plan 02).

Purpose: A teammate gets a branded, professional email with a single working
accept link that names the company, their role, and when the invite expires.
Output: `lib/email/invite-emails.ts` + its behavioral test.
</objective>

  <action>
    Create `lib/email/invite-emails.ts`. Start with `import 'server-only'`.
    Import `getIntegrationKey, getBranding` from `@/lib/platform-config` and
    `getCanonicalBaseUrl` from `@/lib/utils/site-url`.

    Copy the `escHtml` + `buildEmailShell` helpers and the `FROM_ADDRESS`
    constant from account-emails.ts (mirror, do not re-export — keep this file
    self-contained exactly like payment-emails.ts does).

    Export an interface and function:
    ```typescript
    export interface InviteEmailContext {
      toEmail: string        // the invited person's email
      token: string          // pre-generated by the action (Plan 02) — DO NOT generate here
      role: 'admin' | 'member'
      companyName: string    // the inviting company's name
      inviterName?: string | null  // optional, for the greeting
      expiresAt: Date        // for the human-readable expiry line
    }
    export async function sendInviteEmail(ctx: InviteEmailContext): Promise<void>
    ```

    Implementation (mirror account-emails' sendWelcomeEmail structure):
    1. `if (!ctx.toEmail) return` — skip empty recipient silently.
    2. `const key = await getIntegrationKey('resend'); if (!key) { console.warn('[invite-emails] no resend key — skipping invite email'); return }`
    3. `const branding = await getBranding()`; `const brandColor = branding.primaryColor ?? '#111111'`.
    4. Build the ABSOLUTE accept link ONCE:
       `const acceptUrl = `${getCanonicalBaseUrl()}/invite/accept?token=${encodeURIComponent(ctx.token)}``.
       (The /invite/accept route is built in Phase 137 — here we only emit the link.)
    5. Build an `expiresLine` from `ctx.expiresAt` (e.g. `ctx.expiresAt.toLocaleDateString('en-US', { dateStyle: 'long' })` or `.toDateString()` — pick the simplest deterministic format).
    6. Compose `body` HTML: a greeting (use inviterName/companyName), a sentence
       like "You've been invited to join <strong>${escHtml(companyName)}</strong>
       on ${appName} as a <strong>${escHtml(role)}</strong>." a primary CTA button
       (reuse the brandColor button markup from account-emails) whose `href` is
       `escHtml(acceptUrl)` labelled "Accept invite →", and a line "This invite
       expires on ${expiresLine}." Escape EVERY interpolated string value with escHtml.
    7. `const html = buildEmailShell({ brandColor, logoUrl: branding.logoUrl, appName: branding.appName, body })`.
    8. Build a plain-text `text` body that also contains the bare `acceptUrl` once
       and names the company + role + expiry.
    9. `const { Resend } = await import('resend'); const resend = new Resend(key)`.
    10. `await resend.emails.send({ from: `${branding.appName} <${FROM_ADDRESS}>`, to: ctx.toEmail, subject: `You're invited to join ${branding.appName}`, html, text })`.
    11. Wrap the entire body (after the two early returns) in try/catch; on catch
        `console.error('[invite-emails] sendInviteEmail failed:', e)` and return —
        NEVER rethrow.

    CRITICAL: the raw `ctx.token` must appear ONLY inside `acceptUrl` (html + text
    link). Never `console.log`/`console.warn`/`console.error` the token, never put
    it in the subject. Do not hardcode any Resend key — it comes from getIntegrationKey.
